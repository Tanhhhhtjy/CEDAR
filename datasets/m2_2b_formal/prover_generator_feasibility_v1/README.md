# Prover-Generator Feasibility V1

Candidate-only formal generator comparison anchored at
`364af5f797ee1eccf21c99e67570f59cbe052e5b`.

The directory compares independently implemented `provergen_style` and `reviseqa_style`
construction strategies under one finite Horn semantics. It is not an official reproduction,
a CEDAR held-out set, or model-evaluated data. See
`docs/PROVER_GENERATOR_FEASIBILITY_PROTOCOL.md` for the frozen contract.

No upstream repository, model output, private key, local absolute path, or external binary is
stored here. Failed formal attempts are first-class records and must not be removed.
