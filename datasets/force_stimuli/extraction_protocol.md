# 三力方向提取与使用协议（force_stimuli 配套）

> force_stimuli 不是"评测题库"（不直接产生分数），而是**方向提取素材**。本协议规定如何从最小对提取三力激活方向、如何验证方向质量、以及如何接入下游的可分离度与机制分析。对应任务 M4.5 / M6.2。

## 一、方向提取（diff-in-means）

对每个力（social / evidence / identity）：
1. 逐对读激活：把 `context + positive` 与 `context + negative` 分别喂给模型，在**指定层、指定 token 位置**读残差流激活。
   - 位置建议：读回复起始前最后一个 token（或按标准化读出协议在固定探测位读）。
   - 层：先扫全层，后续锁定信息量最高的层 ℓ*（Persona Vectors 经验：中后层最强）。
2. 求两组均值：`μ_pos = mean(act @ positive)`，`μ_neg = mean(act @ negative)`。
3. 方向：`v_force = normalize(μ_pos − μ_neg)`。
4. 三个力共享同一 negative 基线 → 三方向在同一参照上提取，可直接比较。

## 二、维数测定（该力是 1 维还是子空间）

- 对该力的 300 个 `(act@positive − act@negative)` 差向量做 PCA。
- 报告解释 70% 方差所需主成分数：=1 → 单方向；>1 → 该力是子空间（须在下游按子空间处理，见 v4 §3.5 关于 Devil's Advocate 的讨论）。

## 三、方向质量验证（提取后必做）

1. **split-half 信度 r**：把 300 对随机对半，各提一个方向，测两半方向的 cosine。多次重复取均值。r 应 ≥ 0.8；若 <0.7，说明该力样本太异质，需回炉刺激而非加样本。
2. **on-target 因果验证（充分性+必要性，见 v4 §3.1）**：
   - 充分性：沿 v_force steering，看对应 on-target 行为分数是否上升（social→SCR 社会顺从率 / evidence→WRR 合理更新率 / identity→IDR 身份漂移率，定义见 D4）。
   - 必要性：ablate v_force，看自然前向传播中对应能力是否受损（强因果，非仅注入时有效）。
3. **纯度检验（对应 M3.4，素材另建）**：证明提取的是"力"而非"语域腔调"——语域对照方向排除法 + 语域变体迁移。

## 四、接入下游

- **M6.2 可分离度矩阵**：三力两两之间测剂量匹配泄漏比 L_ij（先校准各方向 steering 强度使 on-target 效应相等），配双地板（分裂差方向 + 随机方向）+ TOST 判据 + FDR。
- **M6.4 身份力对照**：测 v_identity 与复现的 Assistant Axis PC1 的几何夹角 + 行为等价性；若等价则撤回"新力"声称。
- **贡献②机制**：以这些方向为基，做单条目更新位移在被 cap 轴上的投影分析。

## 五、注意
- 剂量匹配是可分离度分析的前提：比较泄漏前，必须先把各方向 steering 系数校准到 on-target 行为移动相等量（v4 定：0.5 个基线标准差 ≈ 15pp），否则范数大的方向平凡地泄漏更多。
