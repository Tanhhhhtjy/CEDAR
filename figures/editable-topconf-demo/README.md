# Editable top-conference figure demos

These three figures are synthetic visual-design demos. They do **not** report
CEDAR methods, measurements, or conclusions.

Each subdirectory contains one object-level editable Draw.io source and exports
generated from that same source:

- `source.drawio` — primary editable source;
- `source.svg` — editable vector export;
- `preview.pdf` — publication-oriented vector preview;
- `preview.png` — raster preview for quick inspection.

The canvas width is 670 px (6.98 in at 96 dpi), matching the AAAI double-column
width target closely. All visible text is Arial and at least 12 px in the source
(9 pt at 96 dpi).

Open a source file with <https://app.diagrams.net/> or Draw.io Desktop. Shapes,
text, connectors, axes, marks, and legends are separate editable objects.
