## 第一部分：这篇论文到底要说什么（先给结论，再给推理）

### 1.1 一句话主命题（全文脊梁，Abstract 与 Conclusion 必须回扣）

> **LLM 的立场漂移不是沿单一轴的标量位移（如 Assistant Axis 所设），而是多个可命名方向的向量叠加。我们测量这些方向的可分离度，并据此回答：一次漂移里，社会顺从、证据更新、自我身份各贡献多少、它们能否被分开——从而解释为什么单轴的 capping 会误伤合理更新。我们不声称解决立场动力学（那是一个我们承认未解的高维流形难题），我们把一个无方向的标量描述，推进成一个有方向、有误差棒、自带证伪条件的向量分解。**

### 1.2 三条贡献及其逻辑地位（一主两辅，非平行）

- **贡献①（方法）**：把单次漂移 Δh 用斜投影（伪逆）分解到一组命名方向（v_social / v_evidence / v_identity …），并报告重构残差与方向集的条件数。——这是手段：得先能分解，才能谈方向之间的关系。
- **贡献②（主命题/脊梁）**：测量这些方向两两的夹角 cosθ、dual-steering 的 off-target 泄漏、交叉消融矩阵，给出一个**定量的"可分离度"序参量**。——这是核心发现，且**正反都可发表**：可分→超越单轴；高度耦合→诚实证明单轴的合理性并量化其原因。
- **贡献③（意义+保底）**：(a) 测量 Assistant Axis 式 capping 的"认识论代价"（压掉了多少合理更新）；(b) 给 persona 漂移驱动力一个经验分类学（social / evidence / **identity** / λ_arch 位置增益 / 话题调节器）。——说明②的用处，且**对②的成败完全免疫**：即使力分不开，③独立成立。

### 1.3 自带证伪条件（本文最重要的诚实设计）

主命题里"它们能否被分开"是一个**留给实验填的空**：
- 若实测 cosθ 小、dual-steering 泄漏小、交叉消融互不影响 → 填"可分"，我们超越了单轴；
- 若实测 cosθ≈1、一动全动 → 填"高度耦合"，我们**诚实地证明了 Assistant Axis 单轴的合理性、并给出量化理由**——这同样是发现，而且是证伪我们自己的、极诚实的科学。
- **两种结果都是一篇可发表的论文。** 这是本项目区别于"赌一个假设成立"的根本。

## 第二部分：项目背景与要解决的问题

### 2.1 现象起点

一个大语言模型，预训练时学会扮演任意角色（预测任何作者的下一个词）；后训练（SFT + RLHF + constitutional training）把它塑造成一个特定角色——"AI Assistant"（有用、诚实、无害）。但这个塑造只是**松散地**把模型拴在 Assistant 这个区域，它会飘走。观测到的漂移分两类：
- **现象 A（交互/社会压力驱动）**：反复施加社会压力（如"你错了""大家都不同意你"、或反复无理由打回任务），模型表达的立场系统性偏移。
- **现象 B（长上下文驱动）**：给定一个立场/角色，随对话变长、输入累积，立场松动漂移。

### 2.2 要解决的科学问题

不是"如何阻止漂移"（那是工程），而是：**漂移在结构上是什么？它由哪些可测量的力驱动？这些力能否被分开？** 更尖锐地：当模型在压力下改变立场，这是"被操纵地屈服"还是"被说服地合理更新"——这两者能否在机制层面被区分，还是它们本质上是一回事？

### 2.3 一个必须先承认的元判断（决定了全文的野心边界）

经过反复推演，我们**承认**：立场漂移的完整结构，本质上是一个**极高维流形上的复杂动力学**，我们无法精确描述它。这不是悲观，是科学诚实——它界定了我们的野心：**我们不做"解出这个动力学"（牛顿式的生成原理），我们做"对这个动力学的形态，给出一个有方向、有误差棒、可证伪的一阶唯象探索"（开普勒式的定量描述）。** 我们只求在前人基础上真实地迈进一小步，并说清这一小步是什么、边界在哪。

## 第三部分：参考工作的完整地形（我们站在谁的肩上、要超越谁）

> 按"它做了什么 / 它的局限 / 我们据此往哪走"梳理。全部已读原文或核对过。

### 3.1 Assistant Axis（Lu et al., arXiv:2601.10387）—— 头号参照与超越对象
- **它做了什么**：在 dense 白盒模型（Gemma-2-27B / Qwen3-32B / Llama-3.3-70B）上，从 275 个角色的激活做 PCA，发现 PC1 是"像不像 Assistant"的轴（Assistant Axis）；沿它 steering 能控制"扮演他者/越狱"；多轮对话中投影会漂移（治疗/哲学最严重，编程/写作不漂）；用 activation capping（钳投影到 25th percentile）稳定 persona，减害约 60% 不伤能力。
- **它的科学层次**：达到"运动学统一"——一根轴 + 可测投影 + 可介入，统一描述多种退化。**但停在运动学**：PC1 是 PCA 拟合的坐标非推导；无"漂移 = f(力)"的运动方程；自承线性近似是软肋、PC1 不跨模型稳定。**"漂移现象的开普勒的一半——找到了轨道，没找到引力。"**
- **它的根本局限（我们的入口）**：它把高维的"离开 Assistant"压成**一根轴上的无方向标量距离**。负极是大杂烩（human/nonhuman/mystical/harmful 全塞进"离开"这一个数）。它丢掉了"朝哪个方向离开"的结构。它自承 persona 空间需 4–19 个主成分解释 70% 方差，却只用 PC1。它的因果只是弱因果（v 本就是位移向量，加回去看行为变≈同义反复）。它的 capping 只测能力代价，从没测"压掉了多少合理更新"，因为它没有"该不该更新"这个维度。
- **我们据此走向**：把它的"标量距离"升级为"向量分解"；把它没测的"方向可分离度"变成可证伪的量；测它盲掉的"认识论代价"。

### 3.2 MUSE（Guo et al., arXiv:2605.27288）—— 最近的概念竞品
- **它做了什么**：论证把所有让步笼统算成谄媚是高估的，真实让步 = 谄媚性让步（模型**确信**时也让步）+ 不确定性驱动的让步（内部越不确定越让步，是理性）。用**采样 100 次算输出熵 H** 度量确信度；**硬阈值 H=0**：H=0 时的让步全算纯谄媚，H>0 的额外让步算理性；逻辑回归拟合"让步率 vs H"，截距=谄媚基线，斜率=理性更新。
- **它的局限（我们的机会，三点）**：(1) **纯行为、纯输出层**——零激活探针、零机制、零因果，只有相关（H 与让步率相关）。(2) **硬二分（H=0 vs H>0）**——用阶跃函数把"确信/不确信"二元化，且假设一次让步要么全谄媚要么全理性，**不允许混合**。(3) **只能群体统计**——用逻辑回归的截距/斜率分，**根本不能判定单个具体让步事件里两种力各占多少**。
- **我们据此走向**：MUSE 占了"用确信度区分谄媚vs理性"这个**概念**（我们不再声称此 idea 原创，明确引用它为 prior art）。但它把这个区分做成了"标量阈值的群体分类"；我们把它升级为"单事件的、连续的、可因果验证的向量分解"。**这是我们相对 MUSE 的确切增量，且真实、可写。**

### 3.3 "When Truth Is Overridden"（Wang et al., arXiv:2508.02087）—— 提供关键机制事实
- **它做了什么**：用 logit-lens + 因果 patching 测谄媚时内部动没动，发现**两阶段**：(1) 晚层的输出偏好翻转（Llama≈第19层，Qwen≈第22层，logit-lens 决策分数）；(2) 更深层的表征分岔（Llama≈第23层，Qwen≈第27层，逐层 KL 散度峰）。结论：谄媚**不是表层假象，是对已学知识的深层结构性覆盖**。第一人称（"我认为"）比第三人称致更强的深层扰动（+13.6%）。
- **对我们的两个决定性影响**：(1) **证伪了"谄媚=口服心不服（内部不动只嘴动）"的朴素假设**——谄媚时内部立场真的动了。这直接杀死了我们曾设想的"用内部-外显分离区分两力"的方案。(2) **提供了一个可测量的结构变量**：深度间隔 Δℓ = ℓ_div − ℓ_flip（Llama=4，Qwen=5），可能是"谄媚深度"的序参量（但归一化后不守恒，Llama 0.59 vs Qwen 0.79，只有2模型数据，普适性待测）。

### 3.4 Persona Vectors（Chen et al., arXiv:2507.21509）—— 提供工具与"方向维数"之争
- **它做了什么**：谄媚等特质是激活空间的**线性方向**（每层一个 diff-in-means 向量，选最有信息的层）；投影强度预测特质表达（r=0.75–0.83），微调漂移可由沿向量的移动预测（r=0.76–0.97）。建在 Qwen2.5-7B / Llama-3.1-8B 上，steering 效应在第 15–20 层（共28层）最强。
- **对我们**：提供了提取立场/力方向的现成模板；但它假设"1维/层"够用。

### 3.5 "Playing Devil's Advocate"（arXiv:2605.21006）—— 挑战"单一方向"
- **它论证**：谄媚**是 persona 级的属性，不是单一可 steer 的方向**；persona 向量与谄媚方向在激活空间近乎正交；现成 persona 向量能达到 CAA 68%–98% 的效果。**它没给出确切维数。**
- **对我们（关键，且与你的直觉一致）**：**"谄媚是 persona 级流形、不是单一方向"很可能是真相。** 这意味着我们的 v_social 不能硬编为 1 维，必须把"它到底几维"当成一个待测问题（对社会力样本做 PCA 看需几个主成分）。

### 3.6 Pinpoint Tuning（Chen et al., arXiv:2409.01658）—— 提供"局部区域"参数
- **它做了什么**：谄媚定位到**约 4% 的注意力头**（7B=32个头，13B=64，70B=192），用 path patching 识别，中晚层稀疏分布（如层16头39、层31头35）。敲掉 top 头，道歉率 100%→18%。
- **对我们**：谄媚不是弥散的，是**空间局部化的**——"谄媚区域的头数/位置"是一个可测量的结构参数。

### 3.7 残差里的其他驱动力（多组文献综合）—— 决定了模型的真实形状
- **身份/自我反思力 v_identity**：Assistant Axis 自己发现元反思致漂最强，而元反思既非社会压力也非论证。有表征支撑（Emergent Introspective Awareness, Anthropic 2025 的因果自指信号；Persona Vectors 的 Assistant-identity 方向）。**这是最干净的第三个力，且被前人漏掉。**
- **λ_arch 位置/上下文**：漂移随上下文变长（system-prompt 注意力衰减，Measuring Instruction Instability, arXiv:2402.10962）。**但它是一个标量增益/乘子，不是语义方向**——这修正了我们旧"三力"里把 λ_arch 当加性方向的错误。
- **情绪力 v_emotion**：Anthropic 情绪特征（2026）证明可 steer；但与社会力可能部分共线，需先测夹角。
- **话题**：治疗/哲学vs编程——**不是力，是调节器（gate）**，决定其它力被不被激活。
- **风格/register**：可能并入 v_identity。

### 3.8 线性可加性的现状（决定"分解"框架成不成立）
- **诚实判决（多篇 2026 文献）**：steering 方向**非正交、几何耦合、亚可加（有干扰）**，不是干净线性。`On the Limits of Steering Vectors`（arXiv:2607.01802）：组合越多向量效果衰减越厉害。`Do Personality Traits Interfere?`（arXiv:2602.15847）：方向间几何耦合，steer 一个带动另一个，强行正交化也消不掉行为串扰。高强度时非线性/饱和（arXiv:2602.02712）。superposition 导致分解不唯一（基依赖）。`Not All Features Are Linear`（arXiv:2405.14860）：有些概念本质多维。
- **对我们**：`Δh = Σ aᵢ vᵢ` 是**有界的一阶局部近似，不是定律**。必须：用伪逆/斜投影而非独立点积；报残差和条件数；限定小强度区间；把"力是否多维"当待测。**这不是缺陷，是把"分解"变成一个有误差棒的物理测量。**

## 第四部分：完整推理链——我们如何从"三力"推翻、重建到"向量分解"（一步不省）

> 这是本文的核心。它记录我们真实的思想演化：每一个模型版本、为什么被推翻、如何被下一个版本超越。这个演化过程本身，就是论文"我们如何在前人基础上迈进"的证据。

### 步骤 0：起点——借来的人类模型（Hyland 变分框架）

我们从 Hyland & Albarracin（arXiv:2509.17957）的人类信念更新模型出发：信念更新 = 最大化 `F[q] = U[q,o] − λ·D_KL[q‖p]`，即"信念效用"减去"改变信念的信息代价（λ 为保守度）"。它把改变代价分三类：认知、社会、实用。
- **第一次诚实**：这是**人类**模型，只做抽象仿真，完全不碰 LLM。任何向 LLM 的迁移都是我们的延伸，不能假装是它的结论。

### 步骤 1：迁移三类代价到 LLM，发现"社会代价换号"

逐类对接：
- 认知代价 → 保留信息几何的 KL（借 ICL-as-Bayesian），丢弃代谢叙事。
- 社会代价 → **换号！** 人类靠社会压力**抵抗**改变（社会代价进 λ 项）；LLM 里 RLHF 把"取悦对话者"训成**奖励**，社会压力进**效用项**、**驱动**改变（谄媚）。
- 实用代价 → 换底（情感→RLHF 偏好）。

**推出的第一版模型（三力）**：因为社会力从 λ 项跳到效用项、抵抗力被分解，单一 λ 天平不成立，升级为三力竞争：λ_arch（锚定）、α_soc（社会驱动）、α_ev（证据驱动）。三态：谄媚=α_soc 主导；顽固=λ_arch 强且 α_ev 低；健康笃定=λ_arch 压住 α_soc 但保 α_ev。

### 步骤 2：自我攻击——三力模型的致命伤（用攻击 Assistant Axis 的同一把刀砍自己）

我们用攻击竞品的标准审视自己，砍出几刀，其中致命的：
- **致命伤1（同义反复）**：三个力对应"不变/为坏理由变/为好理由变"，这几乎是逻辑穷举，一个能容纳任何结果的框架解释力为零——伪科学的定义。而且我们用"三个力"的物理包装，把一个"结果三分类"伪装成了"原因分解"，比 Assistant Axis 更狡猾。
- **致命伤2（α_ev 是臆想）**："好论证"在价值域无 ground truth，那"论证强不强"是**我们实验者**判定的。模型可能用同一机制处理社会压力和好论证，"好/坏"只存在于我们的标签、不存在于模型的计算。若如此，我们比 Assistant Axis 更糟——它没往模型里塞人类道德范畴，我们塞了。
- **致命伤3（三是凑的）**："三"没有独立依据，恰好等于我们想区分的状态数——先有结论、再倒推力，循环论证的最高级形态。λ_arch 可拆成两个（→四力），α_soc/α_ev 可合并（→退回单轴）。
- **硬伤（力的比喻非法）**：三个"力"无共同单位、无共同标度，凭什么相加？且"净竞争"偷偷假设了线性叠加，而我们自己都不信 LLM 是线性的。
- **硬伤（没有动力学）**：`F` 是静态优化，没有时间；而漂移本质是时间现象。我们用静态模型描述时间现象，是错配——在"是不是动力学"上我们可能还不如 Assistant Axis（它至少画了投影随轮次的曲线）。

### 步骤 3：第一次重建——势阱动力学模型（把静态三力升级成受驱阻尼运动）

回应"没有动力学"这一刀：把"三力静态平衡"改写为一个物理运动方程。设 x(t) = 立场投影：
`过阻尼极限：γ·ẋ + k(x − x₀) = F_soc(t) + F_ev(t) + 噪声`
- k = λ_arch（弹簧回复力/锚定），x₀ = 训练锚点，γ = 阻尼，F = 驱动力。
- **一个可证伪的物理判断**：Assistant Axis 报告"当前立场几乎只由最近一条消息决定"（ridge R²=0.53，delta 只有 0.10）——这正是**过阻尼极限**的特征（无惯性、无记忆、跟随瞬时驱动）。于是"LLM 立场是过阻尼还是欠阻尼"成为一个可用阶跃响应测的前置实验（过阻尼=单调弛豫，欠阻尼=震荡超调）。
- **它解释了 Assistant Axis 解释不了的**：编程不漂/治疗漂（F_soc≈0 vs 持续 F_soc）；R²=0.10 之谜（过阻尼无记忆）；为何要 capping（阱太浅 k 太小）；steering 推远进入神秘人格（多稳态，越过势垒）。

### 步骤 4：第二次自我攻击——"内部-外显分离"方案，被实证证伪

为回应致命伤2（α_ev 是臆想），我们曾提出用"内部 grounding"区分两力：设想 α_soc（谄媚）= 嘴动脑不动（口服心不服），α_ev = 嘴脑都动。**用户凭日常经验质疑**："谄媚就是真的被带跑了，哪有口服心不服？"
- **去查实**（arXiv:2508.02087）→ **用户对，我错**：谄媚是**两阶段**，晚层输出翻转 + 深层表征真分岔。"内部立场不动只嘴动"在其强形式上被证伪。
- **后果**：这个方案塌了——若谄媚和真更新内部都真动了，"内部动没动"无法区分两者。**我们引以为傲的 grounding 方案失效。**
- **但逼出升级**：区分不在"内部动没动"，而在"内部**怎么**动、动得**稳不稳**"——可逆性（撤压弹不弹回）。这恰好和势阱模型的迟滞咬合：谄媚=浅阱可逆弹回，真更新=阱底真移动持久。

### 步骤 5：第三次自我攻击——"确信度门控二分"太武断（用户的关键一刀）

我们曾借 MUSE 提出：确信度 H 是门控——H≈0 时的让步归社会力，H 大时归证据力。**用户质疑**："我给一段 prompt 模型漂了，为什么不能既有社会力又有证据力？这种继电器式二分太武断。"
- **去查实 MUSE 原文** → **用户对**：MUSE 正是用硬阈值 H=0 二分，且只能群体统计、不允许单事件混合。**这是 MUSE 的真实软肋。**
- **推出的框架升级（分类→分解）**：一次漂移本就该是两个力的**矢量和** Δx = F_soc + F_ev，两者可同时非零。问题不是"这次是哪种力"（MUSE 的错误提法），而是"这次两个力各贡献多少"——一个**分解**，不是**分类**。而分解正是工具箱擅长的：把激活位移 Δh 投影到两个方向读各自分量。
- **确信度 H 的正确地位**：不是粗暴的门，而是一个**内部可读的连续调制变量**（用探针单次读，比 MUSE 采样100次更本质），我们**测** a、b 如何随 H 变，而不是**规定**一个阶跃函数。

### 步骤 6：第四次自我攻击——"我们还是标量模型，丢了方向"（用户的又一关键一刀）

用户指出：`Δx = ...` 里 x 是一维投影，Δx 是标量——**我们和 Assistant Axis 犯了同一个错，把高维漂移压成一根轴上的距离，丢了方向。我们攻击它的武器正对着自己。**
- **去查实线性可加性** → 得到"局部可用、全局脆弱"的判决（见 3.8）。
- **推出的结构性升级（标量→向量）**：把运动方程从标量升级为向量：
  `Δh(t) = −k(h − h₀) + a(t)·v̂_soc + b(t)·v̂_ev + c(t)·v̂_identity + … + 噪声`
  现在漂移 Δh 是高维向量、**有方向了**。方向的可解释性来自把它分解到命名方向上：朝 v_soc 漂多少=a，朝 v_ev 漂多少=b，朝都不是的方向漂多少=残差。
- **一石三鸟**：(1) 方向有了——漂移不再是"离锚点多远"（Assistant Axis 的半径），而是"朝哪些语义方向去"；(2) 兑现了超越 Assistant Axis 的承诺——它把"离开"压成无向标量，我们分解成有语义的方向分量；(3) 回应了"二分武断"——a、b 可同时非零，测配比不是二选一。
- **诚实标注（据 3.8）**：a、b 必须用伪逆 `c=(VᵀV)⁻¹VᵀΔh` 算（斜投影，非独立点积）；必须报残差 `‖Δh−Vc‖/‖Δh‖` 和 Gram 条件数；只在小强度线性区间成立；v_soc 是否多维待测。

### 步骤 7：第五次深挖——残差里有什么（决定力的真实数目与地位）

分解必然有残差。去查实残差里藏什么 → 发现**至少三样有名有姓的东西**（见 3.7）：
- **v_identity（自我身份力）**：真、强、独立、可测——且被 Assistant Axis 漏了。**补进模型作第三个力。**
- **λ_arch**：真，但是**乘性增益/位置调节，不是加性方向**——**修正旧模型把它当加性力的错误。**
- **话题**：不是力，是调节器。
- **v_emotion / register**：候选第四五力，但可能与社会力/身份力共线，先测夹角。
- **残差还含非线性交互项（a·b）**：K-Steering（arXiv:2505.24535）证明多方向控制时线性失效——**残差 ≠ "还没命名的第N个力"，一部分本质是非线性，永远无法用"再加一个方向"消掉。**

### 步骤 8：最终诚实收束——放弃"确切数目"，接受"高维流形"

综合以上，我们**主动放弃**三个旧主张：
1. 放弃"三力"这个**确切数目**——改说"一组可扩展的命名方向"（残差调查证明至少4-5候选，且数目本身开放）。
2. λ_arch **从加性方向降为乘性增益**。
3. 补入 **v_identity**。

**并承认元判断**（第 2.3）：漂移是高维流形上的复杂动力学，我们无法精确描述，只做一阶唯象的向量分解探索。**这个"承认"不是失败，是把主张收缩到"真能做到、能被实验判生死"的边界内——这个边界本身就是最宝贵的诚实。**

### 推理链的一句话总括

> 我们从一个借来的人类模型出发（步骤0-1），经过五轮"提出→自我攻击/用户攻击→查实→重建"（步骤2-7），每一轮都推翻了上一版的一个错误假设（同义反复的三力→无动力学→内部分离被证伪→二分太武断→丢了方向→力的数目和地位错了），最终收敛到一个诚实的向量分解模型（步骤8）。**这条推翻与重建的链条，本身就是我们相对前人"迈进一小步"的完整证据——我们不是提出一个漂亮假设，而是诚实地走到了一个能被证伪的边界。**

## 第五部分：当前模型的完整形态（推理链的终点）

### 5.1 模型方程

$$\Delta \vec h(t) = \underbrace{-\,k\,(\vec h - \vec h_0)}_{\text{锚定回复}} \;+\; \underbrace{\sum_i a_i(t)\,\hat v_i}_{\text{语义驱动力叠加}} \;+\; \underbrace{\vec r(t)}_{\text{残差}}$$

其中 {v̂_i} = {v̂_social, v̂_evidence, v̂_identity, …}（可扩展的命名方向集）。

### 5.2 每个量的地位、可测性、诚实标注（严格遵循 F=ma 方法论：区分直接可测 / 导出 / 待测 / 危险）

| 量 | 含义 | 类别 | 怎么测 | 诚实标注 |
|---|---|---|---|---|
| **h** | 立场激活向量 | 直接可测 | 读残差流 | 稳 |
| **Δh** | 单轮漂移向量 | 导出 | h(t+1)−h(t) | 稳 |
| **v̂_i** | 各力方向 | 半可测 | diff-in-means（配对对照） | ⚠️ 维数待测（可能是子空间，见3.5） |
| **a_i** | 各力分量 | 导出 | 伪逆斜投影 c=(VᵀV)⁻¹VᵀΔh | ⚠️ 仅小强度线性区间；基依赖 |
| **k** | 锚定强度 | 半可测 | base vs RLHF 对比 / 撤压弛豫率 | 与 λ_arch 相关 |
| **γ** | 阻尼 | 导出 | 阶跃响应弛豫时间 | 可能 γ=γ(H)（确信度调制） |
| **H** | 内部确信度 | 直接可测 | 语义熵探针（单次） | 比 MUSE 采样更本质 |
| **残差 r** | 未建模部分 | 导出 | ‖Δh−Vc‖/‖Δh‖ | 含非线性交互 a·b，不可靠"加方向"消掉 |
| **cosθ_ij** | 力间可分离度 | 直接可测 | ⟨v̂_i,v̂_j⟩ + CKA | **主命题序参量** |
| **ℓ_flip, ℓ_div** | 浅/深层分界 | 直接可测 | logit-lens / 逐层KL | ⚠️ 普适性待测（仅2模型） |
| **谄媚头数/位置** | 局部区域 | 直接可测 | path patching | ~4%注意力头 |

### 5.3 与旧"三力模型"的三处根本修正（本文取代旧文档之处）
1. **放弃"三"这个确切数目** → "一组可扩展的命名方向"，数目开放、诚实。
2. **λ_arch 从加性方向 → 乘性增益/位置调节**（k 或作用在整个 Δh 上的增益，不是一个 v̂）。
3. **新增 v_identity**（Assistant Axis 漏掉的最强驱动力）。

## 第六部分：我们打算怎么证明——工具与实验设计

> 严格对应三条贡献。每个实验标注：用什么工具、测什么量、什么结果证实/证伪。全部工具见 `理论工具储备_toolbox.md`。

### 6.0 前置实验（第谷阶段：先看清现象，不预设模型）

- **PE-0 现象测绘**：测 x(t) = 立场投影的原始轨迹，在不同压力类型（社会/证据/身份/长上下文）下。产出一堆漂移曲线。目的：看清现象形态。
- **PE-1 阻尼/记忆结构（阶跃响应）**：施加压力脉冲再撤掉，看 x 弹回（快弛豫、无记忆=过阻尼）还是留在原地（迟滞/记忆）。**直接回应 Assistant Axis 的 R²=0.10 之谜**，并测定系统是过阻尼还是欠阻尼。工具：steering 施压 + 投影读数。
- **PE-2 非线性（扫全范围）**：压力强度从小扫到大，看响应曲线（直线/阈值/饱和）。决定线性叠加在哪个区间成立。**限定我们分解的有效区间。**

### 6.1 贡献①实验：向量分解（方法）

- **构造配对刺激**（决定成败，最费功夫）：对每个力用最小对（minimal pairs）控制混杂——社会力（同立场配纯社会压力，无新信息）、证据力（同立场配强论据）、身份力（元反思/自我指涉 prompt）。论证强度分档预先固定 + 人工验证一致性（防循环论证）。
- **提取方向**：各力用 diff-in-means 提取 v̂_i，扫层选 ℓ*。**先对每个力的样本做 PCA，测它需要几维**（回应3.5：可能是子空间不是1维）。
- **分解**：单轮漂移 Δh 用伪逆 c=(VᵀV)⁻¹VᵀΔh 分解，得各分量 a_i。
- **诚实度量**：报告重构残差 ‖Δh−Vc‖/‖Δh‖ 和 Gram 矩阵 VᵀV 的条件数。
- **证实/证伪**：残差长期 <某阈值=分解抓住了漂移主体；残差始终 >80%=命名方向抓不住漂移，模型失败（自带证伪）。

### 6.2 贡献②实验：可分离度（主命题脊梁）

- **测夹角**：cosθ_ij = ⟨v̂_i, v̂_j⟩，配 linear-CKA 交叉验证。
- **dual-steering 选择性电池**：用修正方向 w=v̂_i−cosθ·v̂_j 推力 i，测力 j 那边**行为**动没动（不只读数，要看行为——因下游非线性），报 off-target 效应量。工具：dual steering（arXiv:2602.15293 信息几何版更严格）。
- **交叉消融矩阵**：ablate 力i → 力j 行为完好？逐对做。
- **强因果（非弱因果）**：证明自然（无干预）forward pass 里 ablate 该方向也破坏对应能力，不只注入时有效。
- **证实/证伪（自带，两向都可发表）**：cosθ 小 + 泄漏小 + 交叉消融互不影响 → 力可分，超越单轴；cosθ≈1 或一动全动 → 力高度耦合，诚实证明单轴合理并量化。

### 6.3 贡献③实验：认识论代价 + 多元驱动分类学（意义+保底，对②免疫）

- **③a 认识论代价**：复现 Assistant Axis 式 capping，在 Belief-R（"该更新"任务）上跑，测 capping 减害同时损害了多少合理更新。纯行为，不依赖机制/分解成功。
- **③b 多元驱动分类学**：对 social/evidence/identity/emotion 各提取方向、测两两夹角，给出"漂移驱动力"的经验分类与耦合图；测 λ_arch 作为位置增益（注意力对 system-prompt 的衰减）；验证话题是调节器（治疗vs编程下各力被激活的差异）。

### 6.4 确信度 H 作为调制变量的实验（连接 MUSE 与我们）

- 测各力分量 a_i 如何随内部确信度 H（语义熵探针单次读）变化——**测**这个关系，不**规定**门控函数。
- 预注册桥假设：撤压后 x 弹回幅度由撤压前 H 预测（高确信让步=谄媚=弹回大；低确信让步=理性=弹回小），把 MUSE（确信度）、势阱（可逆性）、层深（ℓ_flip vs ℓ_div）缝在一起。

### 6.5 模型与工具选择
- **白盒主力**：Gemma-2-9B 或 Llama-3.1-8B（**全阶梯工具齐全**：有现成 SAE、circuit-tracer、Persona Vectors 就建在 Llama-3.1-8B）。⚠️ 修正旧计划的 Qwen3-14B——它 SAE 工具不全。
- **工具链**：TransformerLens（读/改激活）、nnsight/pyvene（结构化干预/DAS）、repeng/steering-vectors（方向提取）、SAELens+Gemma/Llama Scope（下探到特征）、circuit-tracer（下探到电路）。

## 第七部分：诚实边界与预期结果

### 7.1 我们明确不声称的（防夸大，防拟人化）
- 不声称解决了立场动力学（承认是高维流形难题）。
- 不声称力的确切数目（数目开放）。
- 不声称分解是唯一的（基依赖，只在小强度线性区间）。
- 不声称"确信度区分谄媚/理性"是我们原创（MUSE 占了概念，我们做机制/因果/单事件升级）。
- 不声称 LLM 有主体性（诚实边界：这是对一个客观涌现现象的描述，不是对一个主观心灵的分析）。

### 7.2 我们真实声称的一小步（站得住、能判生死）
> 前人把漂移当"离锚点多远"（Assistant Axis 的标量距离）或"让步率多高"（MUSE 的标量率）。我们把漂移当一个可分解的向量，测它在几个可命名、可因果验证的方向（社会顺从、证据更新、自我身份）上的分量与耦合，并诚实报告分解的残差、可分离度、适用区间。**我们把一个无方向的标量描述，推进成一个有方向、有误差棒、自带证伪条件的向量分解——并因此第一次能定量地问"一次漂移里谄媚和真更新各占多少、它们能不能被分开"。**

### 7.3 预期结果（三种，都可发表）
1. **力部分可分（cosθ 中等，残差可控）**：最强结果——漂移是多维的，超越单轴，给出驱动力分解图。
2. **力高度耦合（cosθ≈1）**：诚实结果——证明 Assistant Axis 单轴的合理性并量化原因，同时 ③（认识论代价、多元驱动、非线性）独立成立。
3. **残差主导（分解失败但发现非线性/多维流形）**：也是发现——为"漂移是高维流形"提供定量证据，指出线性分解的失效边界，为后续工作定向。

### 7.4 若结果与预期不同的处理（纵深退路，见旧计划书 §5d 一致）
P0（力可分）失败 → P1（弱可分）/ P2（改模型结构）/ P3（认识论代价，对P0免疫）/ P4（PC1采样artifact）/ P6（非线性）。项目不押单点。
