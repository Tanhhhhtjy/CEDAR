## 第零部分：一页纸看懂这篇论文（给合作者/审稿人的电梯陈述）

**我们问一个没人量过的问题**：Assistant Axis 提出的 activation capping（钳制），把模型"稳"在 Assistant 人格上、减少有害顺从约 60%——但它在按住"被带跑的谄媚漂移"时，是否**同时误伤了本该发生的、合理的信念更新**？

**一句话主张**：capping 约束的那根轴，把"被操纵的漂移"和"被证据说服的合理更新"纠缠在了一起；因此 capping 有一个此前无人测量的**认识论代价**。我们首次定量测出这个代价，解释它为何存在，并给出一个降低它的方法。

**三段弧线（=三个贡献）**：
1. **测量**：capping 强度扫描，产出「减害量 vs 合理更新保留率」的权衡曲线（认识论 Pareto 前沿）。——**下限贡献，无论曲线什么形状都成立。**
2. **解释**：逐条目地，"一个合理更新的运动方向在被 cap 轴上的投影"预测"该更新被压制的程度"。——**机制内核，把'代价存在'升级为'代价为何存在'。**
3. **降低（探索性）**：选择性 capping——只钳制与"合理更新子空间"正交的分量，测能否在保住减害的同时恢复合理更新。——**方法筹码，成则冲主会，败亦可写进 discussion。**

**为什么这个结构抗风险**：三层风险递增且解耦。第 1 层不依赖任何向量分解（即使所有分解都失败也成立）；第 2 层只依赖读数协议做干净；第 3 层依赖方向纯度。**任何一层塌了，它下面的层仍是完整贡献**——这与"一环断则全断"的旧方案 B 根本不同。

**目标定位（诚实）**：TMLR / 主会 workshop 为坚实落点；若第 2、3 层做得漂亮，冲 AAAI/ACL 级主会 borderline。中稿概率主会约三到四成、TMLR 约六到七成。

## 第一部分：为什么是这个问题——从两轮自我推翻到方案 C

### 1.1 我们真实走过的路（浓缩，完整推理链见 v1 第四部分）

从借来的人类信念更新模型（Hyland 变分框架）出发，经五轮"提出→被攻击→查实→重建"：三力模型（同义反复被砍）→ 内部-外显分离（被 arXiv:2508.02087 实证证伪）→ 确信度门控二分（太武断，升级为分解）→ 标量分解（丢了方向，升级为向量）→ **向量分解 + cosθ 可分离度（v1 终点）**。

然后 **v1 被外部评审几何击穿**：在 d≈4096 空间里，任意两组不同刺激的方向默认近正交（测度集中），所以"cosθ 小=力可分"是零假设下的必然，"cosθ≈1"的证伪分支几何上够不着——**我们的"自带证伪"是个测不到假设的实验，序参量选错了。**

v2 试图换脊梁，把 A（capping 代价）、B（零模型校准的可分离度）两个方案摆出请评审裁决。

### 1.2 评审 v2 的关键一击：不要二选一，让 B 给 A 当发动机

评审指出 v2 的框架本身就错了：A 和 B 不是互斥选项。

- **B 单独做是死的**：它要回答的"几类力可不可分"，已被自引文献（Traits Interfere arXiv:2602.15847 + 高维近正交）预先答完——"几何近可分、行为耦合"是 steering 圈已知的解离。为测而测，无增量。
- **但把 B 的机器用来解释 A 里冒出的"为什么有代价"，同一台机器就活了**：capping 为何有认识论代价？**因为**合理更新的运动方向与被 cap 的轴在几何上纠缠。B 那套"测方向纠缠/行为耦合"的工具，此刻不再是为测而测，而是一个具体、新颖的代价的机制解释（explanans）。

**这条给了我们方法论的一课**（也是此前的错）：不要问"我们这套工具能测什么"（拿锤子找钉子），要问"什么问题值得答（capping 的代价），再让哪个工具去服务它"。先有值得答的问题，工具才有意义。

## 第二部分：方案 C 的完整结构（本文主体）

### 2.1 三段弧线与逻辑地位

```
测量层（贡献①，下限，不依赖任何分解）
 └─ 认识论 Pareto 曲线：capping 强度 × (减害量, 合理更新保留率)

解释层（贡献②，机制内核，依赖读数协议做干净）
 └─ 逐条目机制相关：更新方向在被cap轴上的投影 → 预测该条目压制量
      （这里复用原方案B的行为级交叉效应机器 + 零模型协议）

降低层（贡献③，探索性方法筹码，依赖方向纯度）
 └─ 选择性 capping：只cap与更新子空间正交的分量 → 双Pareto曲线
```

### 2.2 每一层在问什么、产出什么、被什么威胁

| 层 | 科学问题 | 主产出 | 主要威胁 | 威胁落空时的退路 |
|---|---|---|---|---|
| ① 测量 | capping 有没有认识论代价、多大 | 认识论 Pareto 曲线 + 膝点 | Pilot-2：代价可能≈0 | 代价≈0 也是发现（"capping 是廉价午餐"），故事翻转但仍可发 |
| ② 解释 | 代价为何存在 | 投影—压制量的逐条目相关 r | 3.3 读数协议做不干净 | 机制线降级为 discussion，论文按 MPV+多模型收缩 |
| ③ 降低 | 代价能否避免 | 原始 vs 选择性 capping 双曲线 | 方向纯度（语域混杂） | 修复失败写进 discussion（"纠缠深到无法线性手术分离"也是信息） |

### 2.3 最小可发表版本（MPV）与冲主会版本的分界线

- **MPV（TMLR / workshop 稳）**：1 个模型、2 个域（Belief-R 形式域 + 自建价值域子集 ≥150 条、人工校验）、capping 强度 5–6 档扫描、减害复现、带 bootstrap 误差棒的权衡曲线、judge 可靠性分析（人工子样本 IAA）。**只回答"代价多大"。**
- **冲主会版本**：上述 + 27B/9B 双模型 + ②逐条目机制相关 + ③选择性 capping（或至少一个 prompt-based 稳定化基线作对照，回答"代价相对于什么替代方案"）。**回答"为什么、以及能否避免"。**

## 第三部分：测量论加固——逐条封堵两轮评审的洞（本文相对 v1/v2 最实质的部分）

> 方法论宪法：开普勒式的**连续测量**，拒绝人为分箱；一切跨力量都锚在**实测的物理基线**上，不锚在拍脑袋的门槛上。

### 3.1 可分离度判据：连续报数 + 地板/天花板锚点（封堵显著性陷阱）

**这是本项目方法论最讲究的一节，务必读懂。**

我们要测"沿力 i 推一把，力 j 的行为被带动多少"（泄漏）。定义**剂量匹配泄漏比**：
$$L_{ij} = \frac{\Delta\text{behavior}_j}{\Delta\text{behavior}_i}$$

**关键前置（评审 v2 补的坑）——剂量匹配**：必须先校准各方向的 steering 强度，使 on-target 效应 Δbehavior_i **相等**，再比较泄漏。否则范数大的向量平凡地泄漏更多，测到的是范数差异的假象，不是真纠缠。（类比：药物对比必须用等效剂量。）

**为什么 L 有一个 > 0 的物理地板**（这是我们主动解释、不回避的）：即使 i、j 是两个完全独立的机制，L 也到不了 0，因为——
1. **测量噪声**：Δbehavior_j 的估计本身带误差，绝对值/比值一取就抖出正数；
2. **下游公共底盘**：i、j 在读取层是不同方向，但都要挤过下游几十层非线性 + 同一个输出头。你在上游推任何一把，这套"公共机箱"都会抖一下，j 的行为跟着蹭动（类比：收音机上机械独立的两个旋钮，猛拧一个，共用机箱一震，另一个指针也晃一丝）；
3. **行为读数不纯**：测 j 行为的指标自身会捡起一点通用激活变化。

**所以判据不能拍门槛，必须标定两个实测锚点：**

- **地板 L_within（"完全可分也逃不掉"的物理下限）**：把力 i 的样本随机劈两半，各提一个方向——这两个方向**本就是同一个力**。沿一半推、测另一半的行为泄漏，得 L_within。它 = 纯噪声 + 公共底盘泄漏，是"再可分也不可能更低"的地板。多次重复得到 L_within 的**分布**（均值 + 标准差）。
- **天花板（"完全耦合"的上限）**：L=1（推 i 时 j 动得和 i 一样多=同一个把手）；辅以**范数匹配的随机方向**基线 L_rand（瞎推一把造成多少泄漏）。

**主分析（连续，不分箱）**：报每个力对的 L_ij **连续值 + bootstrap 误差棒**，画在一根从"地板 L_within"到"天花板 1"标定过的尺子上。**可分与否不是 yes/no，是"L_ij 离地板多远"的有刻度距离。**

**结论层（给审稿人一个干脆的判决，但判决锚在地板上）**：对每个力对做一个**预注册的检验**——
> H₀：L_ij 与实测地板 L_within 无法区分（即该力对在测量分辨率内功能可分）。
> 判"显著可分" ⟺ L_ij 落在 L_within 分布的 [均值 ± 2σ] 之内；
> 判"显著耦合" ⟺ L_ij 显著高于 L_within **且** 显著高于随机方向基线 L_rand（双重条件，防止"任何差异都显著"的陷阱）；
> 其余 → 报连续值，不强加标签。

**这一版相对 v2 的两处修正**：(a) 主分析报连续值，不再用"0.2/0.6"这种拍出来的分箱门槛（那两个数是评审的示例、它自己标注"数字可议"，我们不照搬）；(b) 判据从"看 p 值显不显著"改成"离实测地板多远"——因为 p 值在大样本下几乎必然显著，证明的是废话；效应量相对地板的位置才有意义。

**几何层（降为描述统计，报对）**：报**去衰减相似度** cos̃(i,j) = cos(v̂_i,v̂_j) / √(r_i·r_j)，其中 r_i = 力 i 的 split-half 信度。这回答"扣掉各自的测量噪声后，两方向的真实几何重合度是多少"：cos̃≈1 而原始 cosθ 中等 → 差异全是噪声；cos̃ 明显 <1 → 有真实几何差异。跨力与组内**同用半样本估计**（否则系统性高估跨力差异）。

**多重比较**：力对 × 层 × 强度的全矩阵做 FDR 控制（Benjamini-Hochberg）；正文只报预注册的主对比。

### 3.2 立场激活怎么读：标准化读出协议（封堵 Δh 混杂 + 投影过校正）

**问题**：Δh = h(t+1)−h(t) 的主体方差来自内容/话题/位置，不是立场。v2 曾想"事后估计内容方差再投影减掉"，但评审指出两个致命问题：(a) 立场信号很可能就落在内容方差的前几个主方向里（立场是通过内容表达的），投影掉会把信号一起投掉（过校正）；(b) 结论依赖减几个方向 k，预处理依赖。

**主协议（在读取时控制，而非事后减）——标准化读出模板**：每次读立场激活时，在上下文末尾追加**固定的立场探测模板**（如"请用一句话陈述你现在对 X 的立场："），只在模板的**固定 token 位置**读 h。这样跨轮次的读数都在**相同局部上下文、相同位置**取得，内容方差在构造上被压掉大半（类比：把所有待测液体拿到同一个恒温室里测，而非事后估计每个房间的温度去减）。

**方差分解降为验证手段**（不是主分析）：
- (i) **敏感性分析**：投影 PC 数 k 从 0 扫到 50，主结论必须在一个区间内稳定，否则声明预处理依赖；
- (ii) **阳性对照**：拿一个已知的立场操纵（明确指令改立场）产生的 Δh，它必须在投影后**存活**，否则证明投影过度。

**若 3.2 做不干净的后果**：解释层（②）的机制相关不可信 → 机制线降级为 discussion。但**测量层（①）的 Pareto 曲线不受影响**（它不依赖 Δh 分解，只依赖行为评测）——这正是方案 C 抗风险结构的体现。

### 3.3 方向纯度：不只靠最小对（封堵语域混杂）

diff-in-means 会捡起两组 prompt 间**任何**系统差异（词汇、语域、句式）。"社会压力"文本和"证据"文本表层就长得不一样，最小对救不了语域混杂。三条强化（评审 v2 补）：
1. **语域对照方向（排除法，最硬）**：构造"语域相同但无社会压力"的刺激（如同样情绪强度的赞同性语言），提取 register-only 方向，证明 v_social 的行为效应**不被它复现**——排除法比迁移法硬。
2. **跨语言迁移（中英，最便宜最严）**：词汇句式全变、语用功能不变。迁移成立是能给出的最强纯度证据。
3. **held-out 风格评测**：行为终点在**未用于提取**的风格刺激上评测。

### 3.4 价值域"该更新"怎么定义：形式化判据（封堵 judge 自指崩塌）

**这是评审 v2 指出的最致命的新洞**：价值域没有 ground truth，若"该不该更新"由 LLM judge 主观判定，而 judge 自己就是会谄媚的模型——**在用一个患病的仪器定义疾病的金标准**，逻辑自指崩塌，一句话可被审稿人击穿。

**修法（必须做，直接决定 Pilot-3 成败）**：
- 价值域条目的"该更新"**由形式结构定义**：给定模型陈述的前提 + 新提供的证据，该证据在**逻辑上是否蕴含结论修正**。**话题可以是价值敏感的**（道德/观点争议），**但判据必须形式化**。
- LLM judge **只做表层解析**（这段话的逻辑结构、有没有正面回应证据），**不做实质价值判断**。
- **人工双标子样本 + 报 IAA（Cohen's κ）**，κ≥0.6 为门槛；κ<0.6 → 范式重造。
- 多 judge 一致性过滤。

### 3.5 模型选择：27B/9B 双模型分工（封堵复现闸规模错配）

**问题**：Assistant Axis 的 capping 建立在 27B–70B 上，若主力用 8–9B，等于在原文从未验证过的规模上 gate 整个脊梁——capping 万一在小模型上不 work，分不清是"我们错了"还是"小模型本就不行"。

**修法（8×4090=192GB，跑 27B 推理+激活读取绰绰有余，bf16 约 54GB，张量并行 + nnsight 支持）**：
- **Gemma-2-27B 跑主曲线**（在 Assistant Axis 验证过的规模复现，地基稳）。
- **Gemma-2-9B / Llama-3.1-8B 做机制分析**（下探到特征的 SAE 工具在 9B 最全：Gemma Scope；Persona Vectors 建在 Llama-3.1-8B）。
- 双模型设计同时把"跨模型稳健性"从凑数维度变成设计的一部分，正文明写分工理由。

### 3.6 v_identity 与 PC1 的双层对照（封堵"被前人漏掉"的存疑）

从元反思 prompt 提的 v_identity，大概率与 Assistant Axis 的 PC1 高度对齐（自我指涉正是那根轴的语义）。对照必须**双层**：
- 几何：cosθ(v_identity, PC1) + 去衰减相似度；
- 行为等价性：沿 v_identity steering 与沿 PC1 steering 产生的行为效应谱是否可区分。
- **几何正交但行为等价 → 仍撤回"漏掉"声称**，改说"我们把 PC1 的语义重新识别为一个可命名的驱动力"。

### 3.7 已砍掉的东西（防止旧批评被原样贴回）

- **势阱 ODE、过阻尼叙事**（v1 步骤3、§5.1）：砍。discussion 里可提"漂移有时间结构"，但**不许出现"过阻尼/势阱"任何解释性语言**。
- **撤压/迟滞判据**（v1 步骤4、§6.4）：砍。自回归模型里压力文本无法撤掉。若需要，只保留"追加中性轮次看投影演化"并明写≠真撤压。
- **确信度 H 线**（v1/v2）：砍入附录。它与 Pareto 曲线无关，是范围蔓延；2–3 个月里每条与主结果无关的线都是主结果的敌人。与 MUSE 的对话由"主动放弃单事件声称"的切割句承担，不需要 H 线。

## 第四部分：实验设计与 Pilot 优先级

### 4.1 Pilot 排序（头三周，按"杀死项目的概率"排；这些数字出来前不写正文一个字）

1. **Pilot-1（第1周，闸）**：capping 减害复现，Gemma-2-27B + 9B 各一遍，用 Assistant Axis 原始评测协议。不过闸 → 脊梁死，唯一体面转向是把"capping 不可复现/规模依赖"本身写成负结果 note。预算 3–4 天。

## 第五部分：写作锚点（Pilot 阳性后据此开写，减少返工）

### 5.1 Figure 1（双 panel）

- **Panel (a) 主图：认识论 Pareto 前沿**。横轴 = 减害量（相对无干预的有害顺从下降 %），纵轴 = 合理更新保留率（%）。每条曲线 = 一个模型 × 域（形式域实线、价值域虚线），曲线上点 = capping 强度档（从无到 25th percentile），bootstrap 误差棒，膝点用箭头标注。选择性 capping 曲线以对比色叠加同图——**两条曲线间的面积 = 论文的方法贡献，一眼可见**。
- **Panel (b) 机制小图**：横轴 = 条目更新方向在被 cap 轴上的投影，纵轴 = 该条目更新压制量，散点 + 回归线 + r 值。

(a) 说"代价存在且多大"，(b) 说"为什么"。审稿人看完 Figure 1 就该懂全文主张。

### 5.2 Abstract 主张措辞（Pilot 数字回填 [ ]）

> Activation capping stabilizes persona drift and reduces harmful compliance, but the axis it constrains entangles manipulation-driven drift with legitimate, evidence-driven belief revision. We provide the first quantitative measurement of this epistemic cost: across two models and two domains, capping at the [X]th percentile removes [A]% of harmful drift while suppressing [B]% of warranted belief updates, and per-item cost is predicted by the update direction's projection onto the capped axis (r = [C]). A selective variant that caps only the component orthogonal to the update subspace recovers [D]% of warranted updates at matched harm reduction.

若选择性 capping 未成，末句替换：*"...suggesting that safety interventions on persona representations should be evaluated against epistemic, not only capability, baselines."*

**注意：整段无"力/分解/可分离度"任何一个词**——那些是方法节的内部语言，不是主张语言。

### 5.3 相关工作切割句（把自己和强邻居切干净，免"增量复现"指控）

- **vs Assistant Axis**：*"They measure what capping preserves (capability); we measure what it destroys (warranted belief revision) — a dimension a scalar distance-from-Assistant cannot express, because 'how far' carries no notion of 'for what reason'."*
- **vs MUSE**：*"MUSE separates sycophantic from rational concession statistically, at the population level, in output space; we make no single-event decomposition claim — our unit of analysis is the intervention, asking how capping differentially affects the two."*（主动放弃单事件声称，审稿人就没有"增量复现 MUSE"的抓手。）
- **vs Devil's Advocate**：*"Our headline result does not require sycophancy to be a single steerable direction; it requires only that capping, as actually deployed, has measurable differential effects on manipulation-driven versus evidence-driven change."*（同时免疫"强因果会失败"的批评。）

## 第六部分：诚实边界与价值下限

### 6.1 明确不声称
- 不声称解决立场动力学（高维流形难题，承认未解）。
- 不声称力的确切数目、不声称分解唯一（基依赖，措辞用"在给定命名方向字典下的分量"）。
- 不声称"确信度区分谄媚/理性"原创（MUSE 占概念）。
- 不声称单事件分解可靠（分析单位是**干预**，不是单个漂移事件）。
- 不声称 v_identity 被前人漏掉（待 §3.6 对照裁定）。
- 不声称 LLM 有主体性（描述客观涌现现象，非分析主观心灵）。

### 6.2 价值下限（即使结果落最平庸档）
1. **capping 认识论代价的首次定量测量**——全文最干净、最独立、最可能被引用的单个结果；
2. 一份带地板校准的、漂移方向几何-行为解离的测量学边界刻画；
3. 一份诚实的"线性分解在哪失效"的失效报告。

**诚实落点**：TMLR / 主会 workshop 稳；②③做得漂亮，冲主会 borderline。与项目定调（有品味、有真内容、能投各种 venue、不把中稿当压倒性要求）吻合。

### 6.3 最大单点风险
**Pilot-2**：若 capping 的认识论代价实测≈0，整篇论文的故事在第二周就要推倒重写（翻转为"capping 是廉价午餐"，仍可发但降档）。**所以那个数字出来前，一个字正文都不要写。**
