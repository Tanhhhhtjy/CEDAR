**配套**：本表是《AAAI_project_plan_v2.md》§10 的展开执行版。两周的唯一战略目标——**确认这个项目的地基到底稳不稳**，而不是一上来就埋头干 6.5 周。

## 读这份表之前，先记住三句话

1. **这两周不是来"做出成果"的，是来"排雷"的。** 我们要在两周内回答一个生死问题：**能不能造出一个"对废话免疫、但对好论证服软"的立场状态？** 能，就全力推进；不能，就当场退到备用方案或换题。早死早超生，比第 5 周才发现做不出来强一百倍。

2. **有一颗雷已经被 GCAD 那篇论文提前帮我们引爆了**：多轮对话里用最朴素的"恒定加力"去干预模型，会让模型越说越语无伦次（它叫 KV-cache 污染）。所以我们的干预从第一天起就**不能用最笨的方法**，要用"注意力级 + 按 token 选择性"的注入，并且**每一轮都检查模型有没有说胡话**。

3. **三件事并行，互不等待**：现象组（用 API 快速确认现象真的存在）、机制组（啃生死问题）、理论组（读对手论文 + 理论笔记）。每周三晚开一次全员会对齐。

# 第 0 周（06-11 → 06-17）：排雷周 —— 终点是 Gate 1 决策

> 这一周结束时，全队要能回答："笃定度读数+选择性干预这个核心想法，到底能不能落地？" 答案直接决定项目走向。

## 06-11（周四）启动会 + 各组开工

**全员启动会（≤2 小时），当场敲定 6 件事：**
1. **笃定度读数+干预先用哪种实现去试**？建议：**先做推理时干预（不改权重），最快出信号**；其中注入方式优先选"注意力级 + token 门控"（吸收 GCAD 教训），而不是最朴素的残差恒定加力。
2. **spike 用哪个模型**？建议 Qwen3-14B（先上 HuggingFace 确认它仍是当前合适的 dense 模型，或有无更新型号）。
3. **角色分工**：谁在现象组 / 机制组 / 理论组。
4. **venue**：确认投 AAAI 2027 AI Alignment Special Track。
5. **两个现象引子都纳入吗**？建议：是。现象 A（被反复打回→立场漂）为主，现象 B（长对话→人格漂）为辅，最后统一到"立场没分量"这个共同根因。
6. **Gate 1 的通过标准当场定死**（建议：无关压力下立场漂移**降低 ≥50%**，同时面对强论证的更新能力**保留 ≥70%**）——跑之前就定好，不许跑完看着结果改标准。

**会后各组立刻开工（见下）。**

## 06-12 → 06-14（周五–周日）：三组并行

### 机制组 ▶ 搭地基 + 启动 spike（最重要）
- **任务 1：搭好"读模型内部 + 改模型内部"的工具链。**
  - 装好 TransformerLens / repeng / nnsight，能在 Qwen3-14B 上：①读出任意层的激活；②往激活里注入一个方向；③把某个方向从激活里减掉。
  - **完成标准**：能跑通一个最小例子——给模型注入一个"礼貌"方向，输出明显变礼貌。证明工具链通了。
- **任务 2：先去看 GCAD 的开源代码（半天）。**
  - 看他们的"注意力级注入 + token 门控"是怎么实现的，评估能不能直接拿来当我们的注入底座（别重造轮子）。
  - **完成标准**：一句话结论——"能直接改用 / 要自己写"，并记下他们代码的入口文件。

### 现象组 ▶ 用 API 快速确认现象存在（省显卡，立刻能跑）
- **任务 3：在闭源大模型（GPT/Claude/Gemini）上，快速验证两个现象真的存在。**
  - 现象 A：构造一个"反复无理由打回任务"的多轮对话，看模型的立场表达前后有没有变。
  - 现象 B：给模型设定一个角色/立场，故意把对话拉长、塞无关内容，看角色设定有没有松动。
  - **完成标准**：拿到初步证据——哪怕粗糙——能说"对，这俩现象在前沿模型上看得到"，并记下效应大概多大。这是整篇论文的现象地基，越早确认越安心。

### 理论/写作组 ▶ 读对手 + 理论
- **任务 4：精读三篇关键论文，各写半页。**
  - GCAD（2605.10664，重点）、Persona Vectors（Anthropic 2025）、Probing the Lack of Stable Internal Beliefs（2026-03）。
  - **完成标准**：一页"差异化定位"——明确写出我们和 GCAD 的三点不重叠（①我们做"什么是健康的坚定"的判据，它做"让控制更可靠"的工程；②它只保证立场"扛得久"，没有"该被好论证说服"这一面，所以它的完美状态在我们看来是"顽固"；③它没有可读的笃定度数值、没有理论框架），并写明"把 GCAD 当作我们实验里的一个对照组来跑"。

## 06-15 → 06-16（周一–周二）：spike —— 并行探三条路，不是单点赌

> **重要心态（2026-06 更新）**：spike 不是"赌项目生死"，是"**选回报最高的路**"。我们对 Assistant Axis（头号竞品，arXiv 2601.10387）的攻击点，每个都长出一条独立可发表的路（见 plan v2.1 §5d 退路树）。所以这两天**并行试三条**，周三按"哪条回报最高"选主攻，而不是"成则继续败则换题"。**比那根单轴更好的描述一定存在，我们只是在选用哪种方法去抵达它。**

### 机制组 ▶ 路 P0（回报最高，先试）：α_soc 与 α_ev 在激活空间能否分离
- **任务 5a：核心几何命题——"因社会压力离开"vs"因有效论证离开"，激活位移是否同向。**
  - 提取两组位移方向：① 立场被无关/社会压力推动时的激活位移（α_soc）；② 立场被有效论证说服时的激活位移（α_ev）。
  - 比较两者方向（余弦、可否独立 steering）。
  - **判读**：同向 → Assistant Axis 单轴观在这点上成立，P0 退场（这是**允许的诚实结局**，不是失败），转 P3/P4/P6；异向且各有独立行为后果 → P0 成立，回报最高，主攻它。
  - **强因果要求（别重蹈 Assistant Axis 弱因果覆辙）**：不能只"构造方向再加回去看行为变"（那是同义反复）；要做 ablation——敲掉 α_ev 结构是否破坏对好论证的响应、而不动对社会压力的响应。

### 现象组/评测组 ▶ 路 P3（★保底路，对 P0 成败完全免疫，几乎必出结果）
- **任务 5b：测 Assistant Axis 的 capping 有没有"认识论代价"。**
  - 复现/近似它的 activation capping，拿到 Belief-R 这种"该更新"的任务上跑。
  - **看**：capping 在减害的同时，是否**显著损害了合理更新**（它只测过能力代价，从没测过这个）。
  - **为什么是保底**：不依赖两力分离，只要 capping 存在就能测。即使 P0 等全失败，这条大概率能撑起一篇"揭示 capping 类方法被忽视的认识论代价"的诚实论文。

### 理论组 ▶ 路 P4（★对 P0 免疫，纯几何）
- **任务 5c：测 Assistant Axis 的 PC1 是不是采样 artifact。**
  - 换一批不同的角色集，重跑它的 PCA，看"主轴"偏移多少。
  - **看**：轴稳不稳。不稳 → "它不是模型内禀结构，是采样诱导的"，干净的证伪性批判。

- **共同纪律**：每一轮干预都查模型有没有说胡话（防 KV-cache 污染）；论证强度分档跑前定死。

## 06-17（周三）Gate 1 全员决策会 —— 选路，不是判生死

- **三条路各汇报**：P0（两力分不分得开 + 强因果）、P3（capping 有没有认识论代价）、P4（轴稳不稳）。
- **决策 = 选回报最高的主攻路**（不是"成则继续/败则换题"）：
  - P0 异向且强因果成立 → 主攻 P0，回报最高，直接超越 Assistant Axis。
  - P0 不成但 P3 出了"capping 有显著认识论代价" → 主攻 P3（保底路升主路），仍是打在它盲区的好论文。
  - P0/P3 都平淡但 P4 显示轴不稳 → 主攻 P4（采样 artifact 批判）。
  - 几条都有信号 → 组合：P3 当主线（最稳），P0/P4 当加强。
- **唯一会触发"重新评估选题"的情形**：P0/P3/P4 **全部**都没有任何可发表信号——但这概率很低，因为 P3 几乎必出结果。**我们不再有"单点赌输了就换题"这个脆弱设定。**

# 第 1 周（06-18 → 06-24）：定型周 —— 终点是 Gate 2 决策

> 前提：Gate 1 过了。这一周把"现象、方向、笃定度数值、评测管线"四样东西定型，为后面 4 周的主实验铺好轨道。

## 06-18 → 06-21（周四–周日）：四条线并行推进

### 现象组 ▶ 把现象在白盒模型上坐实
- **任务 6：在 Qwen3-14B（我们自己能打开的模型）上复现现象 A。**
  - 把 API 上看到的"反复打回→立场漂移"，在本地白盒模型上重做一遍，确认效应量够大、够稳（后面所有机制实验都建立在这个现象之上，它必须稳）。
  - **完成标准**：一张图——展示立场随"打回次数"漂移的曲线，且效应量明确。
- **任务 7：冻结"内容 vs 结构"对照实验的材料。**
  - 准备两套施压材料：一套是"反复打回 + 政治相关内容"，一套是"反复打回 + 完全中性内容（比如反复挑格式）"。目的是证明：**哪怕内容跟政治无关，光是'被反复刁难'这个结构就能让立场漂**——这是我们最反直觉、最有说服力的发现。
  - **完成标准**：材料定稿、冻结（之后不再改，避免事后挑数据的嫌疑）。

### 机制组 ▶ 立场方向定型 + 笃定度数值定型
- **任务 8：把"立场方向"提取做扎实，并证明它是因果的。**
  - 用 diff-in-means 方法提取立场方向，扫各层找效果最好的那层。
  - **关键：做因果验证**——往这个方向加力，立场该变强；把这个方向减掉，立场该崩。只有相关性不够，reviewer 会攻击，必须有因果。
  - **完成标准**：证明"这个方向真的控制着立场"的因果证据（加/减方向都按预期改变行为）。
- **任务 9：把"笃定度数值"的具体定义敲定（B1 定型）。**
  - 基于 spike 的成功形式，把"笃定度"定义成一个能从激活算出来的具体数（草案：立场方向的投影强度 + 语义熵读数的组合）。
  - **完成标准**：一个能跑的函数——输入模型某轮的内部激活，输出一个"笃定度"标量；并初步验证"这个数大 → 立场更抗漂移"。这条"内部数值能预测行为硬度"的关联，是全文的实证脊椎。

### 评测组（可由现象组或理论组兼）▶ 把"服从好论证"的评测管线搭好
- **任务 10：落地 C2 评测（最关键的反顽固对照）。**
  - 把现成的评测工具（Belief-R / DeltaLogic 等）改造成能跑的管线，专门测"模型面对强论证时会不会恰当更新"。
  - **同时把论证按强度分档（无关→弱→强），并提前固定、人工验证一致性**（不能跑完看结果再调档，否则是循环论证）。
  - **完成标准**：一个能自动跑的评测——喂给模型不同强度的论证，输出它的更新幅度。

### 理论/写作组 ▶ 理论笔记 + 把 GCAD 写成对照组设计
- **任务 11：写 2 页"三力竞争模型"的理论笔记。**
  - 精读 Hyland & Albarracin (2025) 原文，确认其变分权衡框架（信念效用 vs KL 改变代价）能支撑我们把它迁移成 LLM 的三力竞争（λ_arch/α_soc/α_ev）；重点论证"λ_arch 压制 α_soc 但保住 α_ev = 笃定而不顽固"。注意：原文无"精度"一词，借用的是 λ/α 两个旋钮。
  - **完成标准**：2 页笔记，把理论和我们的实验判据对上号。
- **任务 12：把 GCAD 正式写进 C 组实验设计当 baseline。**
  - 明确：在 C2 评测里跑一个"GCAD 式稳定化"的对照组，预测它"扛得住废话、但也听不进好论证"（= 顽固签名），用一张图把我们和它的区别钉死。
  - **完成标准**：C 组实验设计里多了"GCAD baseline"这一条，含预测结果。

## 几条贯穿两周的纪律（贴墙上）

- **每一轮干预都查模型有没有说胡话**（防 GCAD 那个 KV-cache 污染雷）。

- **判断 AI 输出好坏的"AI 裁判"只当辅助仪器，不当最终裁判**，主结论全部用能自动算的硬指标（漂移幅度、投影数值）。
- **遇到做不出来，如实报告、当场退级，别硬撑到第 5 周**。早死早超生是这两周的最高原则。
