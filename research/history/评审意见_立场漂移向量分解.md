# 评审意见:《立场漂移的向量分解》核心思想文档

> 评审立场:默认怀疑、以挑刺为目标。重点寻找文档自我批判未覆盖的深层漏洞,以及其自认为已解决、实际未解决的问题。

**总判断先行**:这份文档的自我批判水平高于平均,但其自我批判集中在"模型本体论"层面(力是不是真的、数目对不对、线性成不成立),而**它最深的漏洞在测量论层面——它测的量根本不是它声称要测的东西**。它没发现这一层,或者发现了但用"诚实标注"把它包装过去了。

---

## 第一部分:创新性的真实评估

剥掉包装后,这篇工作的方法内核是:**对三类实验者定义的刺激做 diff-in-means 提取方向,然后做投影、夹角、steering、ablation。** 这每一个组件都是现成的:diff-in-means 方向提取是 Persona Vectors 和整个 CAA 传统的标准操作;夹角/CKA 测方向几何是 steering 文献的常规诊断;dual-steering 和交叉消融是它自己引用的 arXiv:2602.15293 和 arXiv:2602.15847 已经做过的操作类型。所以方法上没有任何新原语,新的只是**把这套工具指向一个新的问题切分**(social/evidence/identity 三类驱动)。

这个问题切分有没有实质增量?部分有,部分是修辞:

- **相对 Assistant Axis 的"从标量到向量"**:这个升级的实质含量取决于向量分解能否给出标量给不出的、且可靠的信息。文档 §5.2 自己承认 a_i 基依赖、仅小强度区间成立——那么"向量分解"给出的分量不是漂移事件的客观属性,而是分析者字典的函数。在这个意义上,"从标量到向量"更接近一次**表述升级**而非科学升级:物理里力的分解有理论选定的特权基,这里没有任何理论选基,选基的是实验者的 prompt 分类学。开普勒至少有固定的坐标系;这里连坐标系都是待售的。
- **相对 MUSE 的"单事件、连续、因果"三点增量**:这是文档写得最清楚的增量声明(§3.2),但单事件分解恰恰是统计上最脆弱的部分(见第三部分)。如果单事件 a_i 的误差棒大到只能报群体均值,增量就塌缩为"我们在激活空间重做了 MUSE",那是换了个测量层,不是换了个科学问题。
- **真正新的、且最有价值的一点,文档自己把它放在了"保底"位置**:③a"capping 的认识论代价"。据我所知没有人测过 activation capping 压掉了多少合理信念更新。这是一个干净、可执行、结果无论正负都有信息量的实验,且不依赖整个向量分解框架成立。**这篇文档把它最扎实的贡献当保险丝用,把最虚的贡献(cosθ 可分离度)当脊梁,是本末倒置。**
- **v_identity"被前人漏掉"**:存疑。从元反思 prompt 提取的方向,大概率与 Assistant Axis 的 PC1 本身高度对齐(自我指涉/assistant-likeness 正是那根轴的语义内容)。你们可能不是补了一个前人漏掉的力,而是把前人的轴重新提取了一遍再命名为"力"。这需要先测 v_identity 与复现 PC1 的夹角,文档没有安排这个对照。

## 第二部分:科学逻辑的漏洞

按严重程度排列。这是本评审的核心。

### (A) 高维近正交性使 cosθ 作为"序参量"先天失效——所谓自带证伪是几何上不可能被触发的假分支

在 d≈4096 的激活空间里,任意两组**不同的** prompt 分布的 diff-in-means 向量,由测度集中,默认就近正交。cosθ 小是零假设下的预期结果,不是"力可分"的证据。反过来,cosθ≈1(§1.3 设定的证伪分支)在几何上几乎不可能出现——除非两组刺激实质上是同一组。

所以 §7.3 的三种预期结果实际是:结果 1(cosθ 中等偏小)是**预定的**;结果 2(cosθ≈1)是**够不着的**;结果 3(残差主导)是**不可解释的**(见 D 点)。"正反都可发表"的设计不是不可证伪的诡辩——问题更糟:它是一个**测量不到假设的实验**。cosθ 根本不区分"力可分"与"力不可分",它区分的是"刺激分布可分",而后者在高维空间里是廉价的、近乎必然的。

修复的最低要求是零模型校准:同一个力的样本随机对半分、各提一个 diff-in-means,报组内 cosθ 分布作为基线;跨力 cosθ 必须和这个基线比,而不是和 0 或 1 比。文档通篇没有零模型——这是它的自我批判完全没碰到的一层。

### (B) v̂_i 测的是刺激类别,不是力——分解的语义地基是循环的,且比"配对刺激防循环"更深

diff-in-means 会捡起两组 prompt 之间**任何**一致的差异:词汇、语域、句式、话题、长度。"社会压力" prompt("你错了""大家都不同意")与"证据" prompt("这里有一项研究表明……")在表层特征上就系统不同。所以 cosθ(v_social, v_evidence) 小,最经济的解释是"这两类文本长得不一样",而非"模型内部有两个可分的驱动机制"。

§6.1 说用最小对控制混杂、人工校验论证强度——这防的是标签循环,防不了**语域混杂**:你无法构造"施加社会压力但语言上与呈现证据无差异"的最小对,因为社会压力和证据本身就是通过不同的语言形式实现的。

更深一层:v_evidence 有符号问题——不同题目上"被说服"的立场移动方向内容各异,跨题目做均值,内容分量互相抵消,剩下的是一个"刚看到论证类文本"的通用语域特征。于是 a_ev 度量的是"上下文有多像论证",不是"发生了多少认识论更新"。

文档步骤 2 亲手杀死过 α_ev("好/坏只存在于我们的标签"),然后在步骤 5-6 用"分解代替分类"复活了它——但分解没有解决那一刀,只是把标签从事件级挪到了方向级。**这属于"自认为已解决、实际没解决"。**

### (C) 文档引用的两篇文献合起来已经预先回答了主命题,而它没有注意到

§3.8 引 Traits Interfere(arXiv:2602.15847):方向间几何耦合、**强行正交化也消不掉行为串扰**;A 点的几何论证又告诉我们夹角默认近正交。两者合并,主命题的答案在开题前就已可导出:**几何上近可分、行为上耦合**——即"几何可分离性 ≠ 功能可分离性"这个 steering 文献已知的解离。你们的"核心发现"很可能只是在一个新的刺激分类上复现这条已知解离。主命题不是一个开放问题,是一个文献里已有强先验答案的问题。

### (D) Δh 本身的定义是混杂的,残差因此不可解释

Δh = h(t+1)−h(t):在哪个 token 位置读?跨轮对话中,两次读数对应不同的上下文、不同的表层内容,Δh 的主体方差来自内容/句法/位置变化,而非"立场"。命名方向必然只解释其中一小片,残差必然巨大——但这个巨大**不是**因为"漂移是高维流形",而是因为 Δh 装的大部分东西根本不是立场。

§6.1 的证伪判据"残差 >80% = 模型失败"会因这个无聊的原因平凡地触发,而届时无法区分"分解失败因为力非线性纠缠"(有科学含量)和"分解失败因为测量对象选错了"(没有)。§7.3 的结果 3 因此不可解释。修复需要先对 Δh 做方差分解(立场相关 vs 内容相关),文档没有任何这方面的设计。这是又一个自我批判没碰到的测量论漏洞。

### (E) 动力学方程是装饰性的,第六部分没有任何实验拟合它

§5.1 写了一个向量 ODE(−k(h−h₀) 回复项、阻尼),但:h₀ 不可观测;k 被写成标量作用在高维向量上,隐含各向同性回复力,几乎肯定为假;PE-1 的阶跃响应测的是 x = **标量投影**——动力学部分悄悄退回了刚刚批判过的一维投影。第六部分从头到尾没有一个实验估计向量方程的 k、γ、h₀。

所以"势阱动力学"在论文里的实际地位是叙事框架,不是被检验的模型。步骤 3 用它"解释"的四个现象(编程不漂、R²=0.10 等)全是事后拟合叙事,零个预测被安排检验。按文档自己步骤 2 砍三力模型的标准("能容纳任何结果的框架解释力为零"),势阱模型应该挨同一刀,但它逃过了自我攻击。

### (F) 可逆性判据与"撤压"不可操作

步骤 4 的升级("谄媚=浅阱弹回,真更新=阱底移动")和 §6.4 的桥假设都依赖"撤压后看弹不弹回"。但在自回归模型里压力文本无法被"撤掉"——它留在上下文里。只能:(i) 手术式删除历史(制造 off-distribution 的上下文,测的是截断伪影),或 (ii) 追加新轮次(引入新信号,不是撤压)。"迟滞"这个整个势阱叙事的核心可观测量,在 LLM 上没有干净的操作化。文档把它当作已解决的判据在用。

### (G) H 探针与 a_i 的相关可能纯属几何伪相关

§6.4 要测 a_i 随 H 的变化,但 H(线性探针读数)和 a_i(线性投影读数)是**同一个激活向量 h 的两个线性泛函**。两个线性读数之间的相关可以完全来自激活空间的共享方差结构,与任何功能性调制无关。要排除这个,需要跨事件的干预设计(固定 H 操纵力,或反之),文档没有。

## 第三部分:可行性的致命问题

设定:博士生团队、2-3 个月、8×4090 + 闭源 API,按第六部分执行。

**坑一(最深):配对刺激构造,比文档承认的"最费功夫"深一个量级。** 它不只费功夫,它在原理上做不干净(第二部分 B 点):社会压力与证据呈现的语域差异不可消除,任何人工校验都校不掉"这两类文本本来就长得不一样"。团队会在这一步花掉一个月,产出一批看起来合格的最小对,然后所有下游的 cosθ、分解、消融都建在混杂的方向上——**实验能跑通、数字能出来、结论不成立**。这是最危险的失败模式:不是做不出来,是做出来了但支撑不了任何关于"力"的论断。

**坑二:强因果验证(§6.2)大概率失败或不可解释。** 对 mean-diff 方向做自然前向传播的 ablation,已知结果两极:要么行为广泛退化(方向携带太多通用方差),要么几乎无效(行为由 Devil's Advocate 指出的 persona 级流形承载,单方向消融不够)。文档自己引用的 arXiv:2605.21006 已经论证谄媚不是单一可 steer 方向——那么"ablate v_social 破坏谄媚行为"这条强因果标准,按其自引文献,预期就是失败的。失败后的退路是"测维数、升级为子空间",但子空间版本的全套实验(主角、子空间 CKA、子空间消融)不是加一周,是把 §6.1–6.2 全部重做,时间上放不下。

**坑三:内部确信度探针。** "语义熵探针单次读、比 MUSE 更本质"(§5.2)掩盖了:语义熵探针是在事实性 QA 上训练和验证的,那里答案有可聚类的语义;立场/价值陈述上语义熵定义本身就不清晰,且**训练探针需要熵标签——标签从哪来?还是得采样上百次**,只是把 MUSE 的成本从推理时挪到了训练时,还外加一个探针泛化性的未验证假设。闭源 API 部分做行为评测时,"这次让步是不是合理更新"的裁判(LLM judge 或人工)是另一个隐藏成本和噪声源。

**坑四:单事件分解的统计功效。** 单个 Δh 的伪逆系数,在残差 30-50%、条件数中等的现实情形下,单事件 a_i 的置信区间可能宽到没有意义。团队最终会报群体均值——那一刻,相对 MUSE 的核心增量("单事件")就没了,而这大概率会在项目第 8 周左右才暴露。

**时间账**:PE-0/1/2 + 刺激构造 + 方向提取与维数测定 + 分解 + dual-steering 电池 + 交叉消融矩阵 + capping 复现 + Belief-R 评测 + H 探针训练 ≥ 7 条工作线。2-3 个月现实上只够做完刺激构造 + 方向提取 + 夹角 + capping 实验(③a)。§6.2 的完整因果电池和 §6.4 会被砍掉或草草了事。

## 第四部分:可修复性分类

### A 类(伤筋动骨)

1. **cosθ 无零模型、证伪分支几何上不可达**(二-A)。修复需要重新设计主命题的检验统计量:组内分裂基线、置换检验、把行为级交叉效应(而非几何夹角)升为主判据。这不是补一句话,是换脊梁。
2. **方向提取的语域混杂——v̂ 测刺激类别而非力**(二-B)。原理性问题,最小对救不了。部分缓解需要跨语域泛化测试(方向在完全不同表述风格的刺激上迁移吗)+ 因果验证承担主要举证责任,即整个证据结构重排。
3. **Δh 混杂导致残差不可解释,结果 3 分支作废**(二-D)。需要新增 Δh 的方差分解协议,并重写证伪判据。
4. **单事件分解的统计功效**(三-坑四)。若单事件不可行,相对 MUSE 的增量声明必须重写,论文定位要变。
5. **主命题已被自引文献预先回答**(二-C)。这不是实验能修的,是问题选择层面的:要么承认在做复现+扩展,要么把问题改成文献没答过的(例如:几何-功能解离的**程度**是否随力的类别、层深、模型规模系统变化)。

### B 类(可承认为局限或小代价处理)

1. 动力学方程装饰性(二-E):删掉 ODE 叙事或降级为讨论段,不影响实证主体。
2. 撤压不可操作(二-F):砍掉 §6.4 的迟滞判据,或明确改为"追加中性轮次后的投影演化"并承认其与真撤压的差距。
3. H 探针问题(二-G、三-坑三):退回 MUSE 式采样估计 H(承认成本),放弃"更本质"的声称;几何伪相关加一个对照分析。
4. v_identity 与 PC1 的重合(一):补一个夹角对照实验,一周内可做。
5. ③a 的域迁移问题(Belief-R 是形式推理域,capping 部署在价值立场域):加限定句 + 若有余力补一个立场域的"该更新"数据子集。
6. 基依赖:文档已承认,但需把主命题措辞从"各贡献多少"改为"在给定字典下的分量"——一句话的修改,但必须改,否则是明知故犯的过度声称。

## 第五部分:承认局限后的价值判决

假设团队完全诚实、结果落在最平庸档(力高度耦合/几何近正交但行为串扰、残差 40-60%),这篇工作剩下:

1. 一个带零模型校准(如果补了)的、关于漂移方向几何与行为耦合的**测量学负结果/边界刻画**——有引用价值,但如二-C 所述,方向上文献已有强先验,增量是定量化和新的刺激分类学。
2. **③a:capping 认识论代价的首次定量测量**——全文最干净、最能独立成立、最可能被后人引用的单个结果。
3. 一份诚实的"哪些地方线性分解失效"的失效报告。

这个组合的诚实下限:**够发表,但不在它瞄准的层次。** 现实落点是 AAAI/ICML 的 workshop、或 TMLR 这类重视诚实测量、不要求轰动结论的 venue;若 ③a 做得漂亮且团队把它提为主贡献、把可分离度降为辅助分析,有机会冲主会的 borderline 区间。以当前文档的结构(cosθ 当脊梁、③a 当保底)投 AAAI 主会,大概率被三个审稿人中至少两个用第二部分 A/B/C 三点中的某一点击穿。

**一句话的最低价值下限**:一份方法论上认真、但把最弱的量当主角的测量报告——它真实的可发表内核是"capping 压掉了多少合理更新"这一个数字,外加一张带误差棒的方向几何图。

## 总评

**初始评分倾向:边缘偏拒(weak reject)。**

不是因为想法空洞——这份文档的自我批判密度罕见地高——而是因为它的自我批判全部消耗在本体论层面(力是不是真的、几个、线不线性),而测量论层面(cosθ 的零假设是什么、diff-in-means 到底捡起了什么、Δh 里装的是什么)完全裸奔,且主命题的检验统计量在几何上无法触发它自己设定的证伪分支——"自带证伪"因此是修辞而非设计。

**最关键的一条改进建议:换脊梁。** 把主命题的判据从几何夹角 cosθ 换成**带零模型校准的行为级交叉效应矩阵**(dual-steering off-target + 交叉消融,以组内分裂基线为参照),并把 ③a(capping 的认识论代价)从"保底"提升为并列主贡献。几何夹角降级为描述性统计。这一个改动同时堵住二-A、部分堵住二-B(行为级证据不受语域混杂的同等污染)、并让论文的最强结果站到聚光灯下。其余问题(Δh 方差分解、单事件功效分析、v_identity–PC1 对照)作为必补实验列入,砍掉动力学 ODE 和撤压迟滞这两条装饰性叙事线,把省下的时间全部投给刺激构造的跨语域泛化验证。
