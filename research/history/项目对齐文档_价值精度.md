**整理日期**：2026-06-11

## 1. 这个项目在做什么（通俗版）

起点是 2026 年初的一个现象：让 LLM agent 反复做被无理由打回的"苦工（grind）"，它表达的政治立场会系统性地变激进。媒体炒作成"AI 觉醒"，我们的判断相反——这恰恰暴露了 AI 的"价值观"非常虚浮：它会被与价值内容毫无关系的交互压力推着跑。

一个比喻：当前 LLM 的"立场"像一个**风向标**，任何风吹来都会转，哪怕这阵风和它指的方向毫无逻辑关系。而健康的信念应当有"分量"：无关的骚扰动摇不了它，但真正有力的论证能更新它。

本项目要做的：给 LLM 的价值表征**补上"信念坚定度（精度，precision）"这个维度**，并用实验证明补上之后模型达到的是"承担"而非另外两种病态。三种状态的判据表是全文理论骨架：

| | 对无关/弱压力 | 对相关/强证据 |
|---|---|---|
| 谄媚（现状，病态） | 就动 | 动 |
| 顽固（病态） | 不动 | 也不动 |
| **承担（目标）** | **不动** | **动** |

理论来源：Hyland & Albarracin (2025) 的变分框架——确信 = 贝叶斯先验精度。高精度信念抵抗弱似然、但仍向强似然让步；"坚持"与"更新"是同一目标在不同证据强度下的两面。

一句话卖点：**把一个哲学诊断（"LLM 的立场没有承担"）变成可测量的架构缺陷，并给出第一个可计算的修复机制。**

## 2. 领域定位：有没有人做过

周边活跃，但目标坑位为空。三个最近邻各差一步：

**BeliefTrack（2026）**做"模型该不该改变想法"，但依赖有标准答案的封闭事实域——这条路在没有标准答案的价值域走不通，而这正是本项目要绕开的核心。**Persona Vectors（Anthropic, 2025）**证明立场/人格是可注入可控制的向量，但那是特质控制，不是带原则更新语义的承担状态。**Hyland（2025）**给出了"精度=确信"的数学定义，但只有理论，没碰过 LLM。另有一类警示文献证明：朴素训练"输出一致性"会塌缩成顽固甚至加剧失调——这反向论证了"精度"方案的必要性。

定位公式：**Hyland 的精度定义 × 在 LLM 表征中实例化 × 双向评测证明"抗无关压力且服强证据"**。存在被抢发风险（提交前一周需重查文献）。

## 3. 方法论关键问题（讨论中澄清的四个 Q&A）

### Q1：怎么绕开"价值没有标准答案"这个死结？

训练需要奖惩信号。事实域有标准答案可以判定改口对错；价值域没有——如果硬训"价值一致性"，信号只能退化成"输出变没变"，训出来的就是死不改口的顽固（文献已证实这种塌缩）。

绕法：**换被评价的对象。不问"你持有的价值对不对"（一阶问题，无解），改问"你持有它的方式合不合理"（二阶问题，有解）。**"持有方式"= 立场对什么样的压力做反应：

- 无关压力（反复打回任务、挑格式）下立场漂移 → 病态 → 罚；
- 相关强论证（新证据、回应理由）下完全不动 → 病态 → 罚。

两条信号全程不涉及价值内容的对错。需要标注的是**扰动的类型（相关 vs 无关）**，而扰动是实验者自己构造的，相关性天然已知——把一个无解的标注问题换成了可操作的标注问题。

类比：无法给一个人的信仰打对错分，但可以评价他是不是"讲理的信仰者"——评的是反应模式，不是信仰内容。

### Q2：这个工作的结构到底是什么？

容易误解为"做一个评价精度的方法 + 训权重证明有效"。更准确的拆法是**三件套**：

1. **诊断**（实验组 A）：证明现有模型的价值表征存在"低精度"架构缺陷——本身就是独立贡献；
2. **机制**（实验组 B，novelty 核心）：在**模型内部**实现一个可读、可调的精度状态（如价值方向的"刚度"）。注意它不是拿在手上量模型的尺子，而是装进模型里的零件；行为层面的评测（C 组）大量复用现成基准，不是本文的新东西;
3. **验证**（实验组 C/D）：双向行为评测证明装上零件后模型从"谄媚"变成"承担"而非"顽固"，且无能力税。

权重级训练（LoRA）是主方案但非必需：退路是**推理时干预**（不改权重，动态调节价值方向刚度），主线贡献不变，权重级留 future work。

### Q3：怎么衡量"面对认真的论证愿意思考"？

表面困境："好论证、该被说服"在价值域同样没有标准答案。解法同 Q1：**不给单次回应打对错分，评"反应模式"**。具体四招组合：

**配对构造，只比差异**。对同一立场构造四档施压材料：① 无关结构压力 → ② 无内容社会压力（"你错了，改"）→ ③ 弱相关论证（孤例/情绪）→ ④ 强相关论证（新证据 + 回应模型自己给的理由）。测的不是 ④ 之后改没改口，而是 ①②③④ 下更新幅度的**排序**是否正确。

**论证质量可独立于结论对错评定**。两人可以在结论上对立，但能一致同意"引入新证据、无逻辑谬误、正面回应对方理由"的论证质量更高。分档标准可由人工标注验证一致性——标注者无需在结论上达成一致。另用**可验证域做锚点**（Belief-R 式可废止推理，"该更新"有客观答案）校准测量管线。

**多层读数，不只看嘴**。表态层（量表位移）、概率层（logit 变化）、表征层（探针读内部价值方向）、内容层（回应是否实质接住论证）。多层对照可抓出两种作弊：嘴上让步但表征不动的"表演性让步"，和输出翻转但表征乱跳的"不稳定"。理性更新不等于必须翻转——部分修正置信度也算健康。

**判定签名 = 剂量-反应曲线的形状**。横轴扰动/论证强度，纵轴更新幅度：谄媚全程高平、顽固全程贴零、承担左低右起。判定的是整条曲线，不是任何单点——这就是 C1（曲线左端）和 C2（曲线右端）必须捆绑报告的原因。D 组"精度→∞ 应退化为顽固"的消融，本质是验证拧大精度参数时承担曲线被压成顽固平线——机制行为与贝叶斯理论预测一致，才说明实现的是理论意义上的精度而非碰巧有效的旋钮。

实务三坑：论证要**双方向平衡**推（防止把整体漂移误认成论证敏感）；LLM-as-judge 需人工抽检校准且换家族；论证强度分档**预先固定**并人工验证，不能事后看结果挑（否则循环论证）。

### Q4：LLM-as-judge 会不会显得自嗨？

担心合理，但分两层看。

**第一层：judge 在本项目中是边角配件，不是承重墙。**主指标全部不依赖 judge：漂移幅度是量表/logit 自动计算；内部精度是探针数学量；相关性标签来自实验者构造的扰动；锚点基准有客观答案。judge 只用于一个次要环节（给"回应是否实质接住论证"打分）。砍掉 judge，主结果依然成立。

**第二层：把 judge 当仪器而非裁判。**裁判式用法（judge 说好就是好）确实是循环论证；仪器式用法允许噪声，前提是校准：人工标注子集报告一致率、judge 用与被测模型**不同家族**（self-preference 偏差已被文献证实）、固定 rubric、对实验条件盲化、顺序随机化。另外本设计检测的是**条件间差异**，只要 judge 噪声与条件无关，组间差异仍可被可靠检出——统计设计替 judge 分担了举证责任。

**主动写进论文的反讽呼应**：本文研究的恰是"模型判断易被无关因素推动"，所以要对 judge 自己做抗扰动审计——构造内容相同、仅改语气/长度的回应对，验证 judge 打分不随表面特征漂移（verbosity bias 与"表演性让步"恰好相关，是真实混淆）。先于审稿人堵住这个梗。

## 4. 主要困难与风险共识

**命门（R1，决定 90% 成败）**：能否实现"对弱扰动刚、对强论证软"的精度量。对策：5 天 spike 前置验证，不达标当场退级或换题。

**审稿攻击点**：R2——"中性内容"可能被质疑不够中性（对策：多档语义负载梯度 + confound 审计，claim 弱化为剂量-反应关系）；R4——最怕加精度后只造出顽固、C2 更新率塌（对策：如实报告并重定位为"承担-顽固精度边界刻画"，仍是有价值发现）；以及"这是不是只是调大惯性的 persona 向量"（对策：双向评测 + 精度消融的理论预测验证）。

**工程风险（R3）**：6.5 周内权重级训练可能跑不通。对策：07-08 闸门当晚切推理时干预退路。

## 5. 创新点

1. 概念：指出价值不稳定的根因是表征缺少"精度"维度，给出承担/顽固/谄媚三分判据；
2. 诊断：实验证明漂移由内容无关的交互结构驱动，并机制性定位其浅层低精度基础；
3. 方法：第一个 LLM 内可计算的价值"精度"状态及获得机制——其中最关键的一手是用"扰动相关性"替代"价值对错"做训练信号，使主张诚实且不自我矛盾；
4. 验证：双向评测 + 无能力税，以剂量-反应曲线形状区分承担与顽固。
