# H1：独立结构确认设计草案

本文件为设计与预算材料，不是已认证题库、冻结的 H1 执行协议或 H1 实验结果。当前服务器仅执行 C1；H1 不以 C1 阳性为前提。Jev 留在未来工作，不参与当前标签或筛题。

## 要确认的内容

优先检验新结构上是否仍存在固定轨迹的 V/F 差异、S1 尺度校正后的残余，以及旧开发集训练的 P1 是否可以直接迁移。C1 完成且管线合格后，可预先选择带入其已经冻结的方向和端点。不能在 H1 标签上重新训练/选方向，再称为独立迁移确认。自然生成行为若另测，应与固定轨迹读出分开，不混称同一证据。

## 结构独立性的审核

旧生成器的 family_plan 明确把多个 family ID 归入同一 structure_class/isomorphism_group，来源为 code/datasets/m2_2b_formal/prover_generator_development_v1/development_common.py 与 data/evidence_certified_pool/family_cards24.jsonl。旧对象规则已含分支、共享 gate、缺失合取项和定向可达性，不能仅把“有分支”当成新结构。

逐项同时审核两个层面：原始任务的规则依赖图，以及 V/F 理由中由前提到修改正当性的推理图。去除实体名、表面谓词名和编号后，比较有符号、带参数位置的规则超图与无标签依赖骨架。仅重新命名、换 salt、延长旧链或换答案字母，均不自动计为独立新结构。新 family ID 数、真正原型数和同构组数分别报告。

候选设计可包括嵌套合取的多级汇合并复用中间证明、存在多条独立支撑路径时的最小割干预、多关系组合中的共享变量约束。它们只是待审核的候选；在与全部旧 PGF-01..08 图谱比较并给出非同构证据前，不宣称新颖。尽量保持原单项原子编辑与真值语义，避免通过更改任务定义制造新结构。若需要多项编辑，另立实验协议和可比性说明。

## 标签与题面门禁

沿用独立的 Python 固定点求解器与 Prover9 双重证明，并以 Mace4 检查 F 反模型。认证 V 的结论可推出；F 仅一个声明的致命错误，补入该错误结论后其下游推理有效，且原世界不能推出目标。双求解器不一致或无法认证的项目记录为生成失败，不根据模型分数筛除。

保留 N/R/V/F 同 base 及同目标；答案身份/初始到目标转换平衡；有效和无效理由长度、选项暴露和提示模板相配。记录 token 长度、证明深度、分支度与错误类型；不以模型是否答对来挑选题。完成自然语言与符号对齐审核后固定全部输入哈希、生成器、求解器版本与分组表。

## 精度与冻结

precision_plan.py 在服务器分析环境计算旧 S1 12-family 方差、同构类别清单，以及不同结构组数量和方差放大假设下的区间半宽。独立结构组是规划单位；更多同构变体不能冒充更多组。旧方差不是新结构方差保证；S1 margin 方差不能直接用于 P1 AUC 或 C1 交互的功效声明。

先选科学上有意义的区间精度/效应范围，再冻结生成数量、认证失败与缺失处理、主指标/多重比较、训练和校准材料、推理次数与时间上限。若可认证的独立结构太少，则定位为小规模跨结构稳健性验证并明确区间，不用大量改名样本夸大独立性。H1 结果出来前不得调整上述规则追求显著。
