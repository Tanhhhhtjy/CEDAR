## 3. 已完成实验怎样用于回复

### S1：主要回答“只用四个选项拟合”

程序按 U logits 的 top256、rank257–4096、tail 分层抽取非选项 token，固定随机划分 fit/test，排除选项及冻结排除项；不是将全部词表 token 都拿来拟合。报告中应使用“非选项词表分层拟合与留出预测”的精确名称。

已有选项预测 RMSE：identity 3.4204；same-prompt scale 1.3209、affine 0.9328；family-out scale 1.3528、affine 1.2315。same-prompt 仍用目标轨迹的配对 P 非选项 logits，只是选项被留出；不能与完全未见轨迹预测混称。

主源仍有尺度校正后 V−F 余项，capped-source specific 结果未一致。不能继续写无条件的“所有连续 V−F 均未检出差异”。要标明新旧端点、来源及开发/补充分析；按真实结构组复核后再定新稿强度。

### P1、C1、B：合起来限制机制主张

P1 增加跨条件可解码证据，但固定阈值 balanced accuracy 只有约0.58–0.60；训练与测试按 family 分离不等于新结构分离。C1 在一处 prompt L53 位点和冻结剂量上未得到方向特异因果支持。B 在同一旧结构集上显示历史计算的 broad 效应，六项 Holm 后只有该项低于0.05。

合理回应：我们补做了审稿人指出的预测性迁移与有限干预测试；结果增强了标签迁移和计算范围的证据，同时未证实原来的解耦机制，因此修订了主张。不能只贴 P1 阳性结果并隐藏 C1。

### Social：已有便宜且具体的修订证据

已有 post-hoc 补充给出：normalized-stem 272组下，margin DID区间[-0.8992,-0.6768] logit；target DID约+2.50pp，区间[+0.00,+4.94]pp。聚类实现是抽取完整题干组并以抽中题目总和/总数计算均值，保留题目加权估计对象，不等于题干等权。

这些是现存报告和代码的核对结果，本轮尚未重新逐条计算。第1天应检查原始配对、归组、seed/精度和与当前稿数据版本一致，随后明确标作补充敏感性，不能变成事前主分析。

### margin充分性的具体反例

按(初始,目标,背景1,背景2)排列：z1=(0,1,2,-2)，z2=(0,1,0,0)。两者 general=1/3，specific=1，但z1选择背景1，z2选择目标。因此两个对比不确定四选项最高分身份，更不能确定非选项文本/截断等无效输出。

这可以直接修文；不需要新增模型实验。若为分析需要补背景差z(b1)-z(b2)，可恢复四选项相对几何的第三自由度，但自然无效输出仍须单独解析。

## 4. 新增GPU只安排一个主包，另留一个条件备选

主包为 H 的真正新结构自然行为验证。先认证候选，按真实依赖组划分与冻结；样本选择看结构、标签、长度和答案平衡，不看 U/P 效果或 Jev 分数。

首包应保持 NRVF、同base、同目标、单原子编辑、四值语义，正式报告所有自然生成输出，包括截断/格式错误。V/F交互、各arm绝对率和四状态都展示。若采集固定重放，重放可用子集另列，不能替代行为分母。

规模在认证后、模型输出前固定。规划示例：12个实际认证结构组×2 bases=24 bases、96 prompts、192条U/P自然生成；若追加U-source主重放则再192条件单元。12不是已认证数量或功效保证，也不能由共享骨架的12个family自动得到。若有足够真实新组，应优先增加组数而非同构变体；若组数少，只能宣称有限结构扩展。

原H三主问题为自然行为、raw broad和校正specific，需在执行前明确首包是否承载全部三项、统一多重比较和行为精度；如采取更小范围，先单独版本化科学协议，不能结果出来后删检验。正式包完成与否由预设完整性定义判断，不以显著性或截止前已完成的有利子集判断。

H是最高价值、同时有结构认证和自然生成时长风险的新工作。第1天做可行性检查，第2天冻结。如果无法及时完成认证，不宣称“H已开始确认新结构”，转入预定备选：既有认证旧题上的有限阈值敏感性。这个备选只回应单强度，不替代新结构。

强度备选包含无cap/原p25锚点和事前选定的较弱/较强阈值；固定模型、题目、层窗和解码，核验阈值方向与校准来源。C1正负方向扰动不算cap阈值扫描。已有锚点只有在输入与科学设置完全相同时才能复用。报告所有固定强度，不按是否单调选择。

不把五天变为新累计GPU墙钟上限；截止日是报告与工作排期约束，已有授权的正常实验不因预测耗时被擅自停止。新包启动前必须按实际资源、自然生成长度与收尾时间判断是否能完整承担。
