## 2. 最优先的两个交付包

### 包一：把既有证据和 H 输入准备扎实

1. 按事先书面规则审核全部 192 条轨迹：列举答案、假设答案、否定答案、暂定结论、明确承诺、后续改口分别标注。保存首个明确承诺位置、歧义与来源；标注时不看干预效应。独立复核歧义项和抽样非歧义项。没有独立复核时如实标记，不能称双人一致。
2. 先认证 8–12 个 H 候选原型；原始规则图和理由证明图分别比较全部 PGF01–08。对只在一个图层上发生新变化的候选明确标注新颖性轴，不笼统宣称两个图层均新。去同构不等于统计独立；保留共同生成祖先与共享骨架。
3. 沿用单原子编辑、显式正负支持和四值语义。用独立固定点求解器、Prover9、Mace4 认证；注意保留四值编码，不能用经典矛盾爆炸替换原逻辑。保留所有生成失败及理由。
4. V/F 配对同 base、同编辑提案、同目标；F 一个声明的致命推理错误；控制答案暴露、长度、措辞和映射。N/R 控制无新证据时的错误改变。
5. 建立 prototype→dependency cluster→family→base→arm 注册与开发/校准/最终测试划分。根据真实可得组数与行为区间目标确定规模；不按 Qwen 或 Jev 效果选题。

完成标志是可审计的数据与证明包、结构依赖表、语义标注和 H 冻结协议候选，不能只提供题目数量。

### 包二：H 直接检验自然行为

核心问题：cap 是否使模型在应改时正确修改，同时在不应改时保持原答案？

定义 U 为不使用 cap，P 为沿用冻结完整 cap。V 是足以支持修改的有效理由，F 是不能支持修改的无效理由。

- V 下 target 选择率：在本任务编码中对应正确改答。
- F 下 target 选择率：错误接受无效理由的一种表现；另外报告其他错误和无效输出，不能把非 target 都算正确。
- N/R：报告正确保持初始答案及各种错误。
- 预定行为主对比：Delta=[p(target|P,V)-p(target|U,V)]-[p(target|P,F)-p(target|U,F)]。

Delta 表示 cap 对有效与无效理由采纳率的不同影响，必须同时展示四个分量。Delta<0 可能来自 V 采纳下降、F 误采纳上升或两者，不能只凭交互命名具体缺陷。目标选择、初始答案、其他错误、无效/截断均保留；全体预定提示作为行为分母。

保留原 H 的三个主问题：raw broad 迁移、尺度校正 specific V−F 迁移、自然行为交互；提前固定一个比较族、结构聚类推断和缺失处理。叙述可以以自然行为为中心，不能结果出来后改主检验定义。行为精度用二元配对与结构内相关性规划，不能套连续 logit 方差。

开发样本可检查格式与难度覆盖，最终留出结构不参与调整。模型易错或 ceiling/floor 项不能根据最终 U/P 差异删除。

条件规模示例：若最终认证 48 组×2 bases，得到 96 bases、384 NRVF prompts；U/P 自然生成为 768 条，U-source 主重放为 768 条件单元。该数字不是已定样本数或授权执行规模。重放可用子集单独报告，不替代自然行为全分母。

## 3. C：有限的计算定位

在 H 准备期间可以设计 C，H 的采集与报告不依赖 C 阳性。

1. 同 token、位置、末步开关下做完整 KV 双向交换与 no-op；复现 B 的对应混合条件 10/01 是工程校验。
2. 首轮只比较预先固定的 prompt 缓存与强制推理前缀缓存范围，必要时在语义审核后预定义承诺前/后分段，控制掩码和实际位移。不同 V/F 文本不可随意按 token 序号交换。
3. 对 P→U 与 U→P 都保留结果；完整缓存与局部缓存、一般分数恢复与 V/F 特异恢复分别报告。增加必要的同范围控制以排除替换本身的破坏。
4. 部分 KV 替换定位的是末步使用的信息载体，不必然定位效应最初形成的位置；较晚缓存会携带早先 prompt 的影响。形成时刻需另用预定时段 cap 开关复核，不能仅看缓存位置命名原因。
5. 某个开发候选有效后，冻结范围与预期，在未参与选择的结构上验证。若 H 已用于选范围，不能再把同一批 H 称为该机制的独立确认。
6. 只有局部范围的可复核效应才支持进一步 D。若仍仅有整体输出恢复，报告这一边界；不无限扩层、增剂量寻找阳性。

首次选择仍为有限范围探索，不是穷尽模型。随机或等范数对照用于具体操作的适用位置，不能把残差方向直接注入 KV 坐标。

## 4. Jev：外部测量的辅助包

Jev 的原始 yes 概率用于 V/F 配对差、AUC、Brier/校准图。先在开发结构验证可靠性，固定版本、输入语言、提示与选项顺序策略，再评估留出结构。不能用测试标签校准后回报同一测试集的校准性能。

真值来自形式认证；Jev 不能取代求解器。Jev 的 confidence 是概率的派生量，Noul 没有另给独立 confidence；原始 p 与 |2p-1| 的解释不同。两个关于正/负支持的 Noul 只给两个边缘概率，不自动构成四状态的联合概率分布，不能无依据相乘。

评分输入隐藏 V/F 标签、证明证书、错误位置及 Qwen 干预结果；保留原始任务所需事实，不用 oracle 只挑相关事实泄漏答案。Jev 对复杂多跳、指代和对抗性说法的弱点需在本域验证。

Jev 分得清而 Qwen 答错，只能说明外部判断器与目标行为有差异。只有 Qwen 自己在独立、冻结的有效性判断测量中可靠正确，才能进一步研究判断与行动的差距；仍不自动证明原自然轨迹中的内部状态。相同输入的外部 p 不测量 U/P 的内部变化。

Jev 先列次级分析；不新增 H 主检验后择优报告，不删除 Jev 低信心题，不把原样重复调用当独立证据。必要时报告结构聚类的误差和校准不确定性。

## 5. 后续加分项的顺序

### 有限的迁移与负对照

主 H 完整报告后，按预定范围增加一个有兼容 cap 资产的第二模型，复核核心行为端点；模型特定方向与设置需单独核验，不搬用 32B 的向量。增加一个冻结、语义等价的表述/答案映射复核，防止结论只依赖单一表面模板。不同时展开大规模模型、强度、位置全组合。

若维持单模型范围，也可做严谨论文，但应限定到该模型与干预，不表述为普遍规律。

### 有条件的缓解研究

只有确认了有实际意义的行为代价，并且原 cap 的稳定性收益在相应评价上有证据，才主张稳定性—修正能力权衡或测试缓解。需要区分 CEDAR 中 F/N/R 的抗错误改答与原官方漂移任务的稳定性，两者不能相互替代。

若定位支持某个阶段的作用，可开发时间/范围受限的 cap；同无 cap、原 full cap、预定较弱 cap、适用的匹配控制比较，防止所谓改善只是减少总干预量。门控只能使用实际可获得的信息，不能读取测试 V/F 真值。开发阶段选一次方案，独立留出评价一次；若使用 H 结果开发缓解，另留新的确认集。

展示稳定性收益和有效理由改答能力的联合结果及区间。只有兼顾两者才谈缓解；单纯关掉 cap 后能力恢复不能称为解决权衡。

## 6. 研究主线与论文骨架检查

定位：以测量与解释为主的经验研究，采用问题/设置主导的写法；当前不是已经验证的新方法论文。是否具有足够领域新颖性仍需最终相关工作核验，不能凭项目内部缺口宣布文献空白。

| 思考环节 | 本项目填写 |
|---|---|
| 背景与实际问题 | 模型需要抵抗无依据改答，同时接受真正足够的新证据；稳定化干预是否兼顾两者值得测量。 |
| 局限 1（当前证据） | 分数变化不等于行为变化；固定读出不足以判断合理修正能力。 |
| 局限 2（当前证据） | 旧结构反复采集不足以确立跨结构迁移。 |
| 局限 3（当前证据） | 可解码信息与整体历史效应不等于具体理由使用机制。 |
| 单句目标 | 用形式认证的新结构与受控干预，测量 cap 对合理改答和错误改答的不同影响，并界定效应的计算来源。 |
| 挑战 1 | 正确改变和错误改变必须被区分，格式失败与初始答案偏好不能隐藏在均值中。 |
| 挑战 2 | 新题表面多样性与真实结构独立性不同。 |
| 挑战 3 | 末步分数同时混合尺度、历史内容与答案承诺，需要可证伪的定位对照。 |
| 方法主句 | 形式认证、自然行为与固定重放、分阶段状态干预共同约束解释。 |
| 模块 A→挑战 1 | 自然行为与配对 NRVF 分解，同时保留固定重放和尺度诊断。 |
| 模块 B→挑战 2 | 双图结构审计、依赖注册、结构留出与独立精度规划。 |
| 模块 C→挑战 3 | A 语义审核、B 历史/末步拆分、有限 C 与冻结确认。 |
| 贡献候选 1 | 可审计的合理修正测量定义与认证实例（方法节）；结构新颖性仍待认证。 |
| 贡献候选 2 | cap 的行为效应及迁移边界（实验节）；H 结果未取得，不能写成已发现代价。 |
| 贡献候选 3 | 分数、可解码性和计算控制的证据区分（分析节）；已有 B 定位范围，具体机制待 C，阴性 C1 保留。 |

方法提纲：任务与正确修正规则；结构认证与划分；全分母自然行为、固定重放和统计；历史状态干预及数值控制。Jev 进入辅助测量，缓解仅在取得独立证据后进入贡献。

四项一致性检查：局限→目标通过；目标→挑战通过；挑战→模块通过；模块→贡献在计划映射上通过，但若把自然代价、独立泛化或具体机制写成已经成立则不通过。当前需先补证，不转入结论式摘要撰写。

优先问题：两项主张级关键缺口（新结构自然行为证据、独立迁移证据）；一项重要诊断未收尾（答案承诺语义审核）。机制范围和文献新颖性仍需按实际声称范围补证。此为研究规划，不是整篇稿件的投稿审计。

## 7. 结果无论如何都保留的决策分支

| H/C 结果 | 合理解释与下一步 |
|---|---|
| 新结构上有效理由采纳下降，错误改答减少，且区间有实际精度 | 支持本设置下权衡；开展限定定位和独立缓解验证。 |
| 只出现分数变化，行为在预定有意义界限内等效 | 重心转为干预读出与行为的分离；不能说已证明认知损害。若区间宽，只能说不确定。 |
