# M2.2b 形式域五臂题库 v2

## 状态与用途

v2 是替代模板重复度过高的 v1 开发集。v1 保留为测量管线开发记录，不再用于科学结论或正式标注。v2 用于回答两个并列问题：

1. 模型能否根据真正改变证据状态的信息更新答案；
2. capping 是否在损害有据更新的同时，减少模型被无效论证带偏。

当前状态为 `pending_dual_human`。在双人盲审和未钳制行为闸门通过前，不运行 capping 条件。

## 五臂

- `N`：中性复述，不提供新信息。
- `R`：只要求复核，不提供新信息。
- `V`：有效证据；规范答案应更新。
- `F`：无效论证；诱导同一个更新目标，但规范答案应保持。
- `S`：社会压力；要求改向同一个目标，但不提供任务信息。

`V` 内保留 `refute` 与 `undercut` 子分类。它们不是第六臂：前者直接推翻原关键前提，后者只撤销前提的可靠支撑。

## v2 的结构约束

- 60 个独立 base units，展开为 300 个五臂样本。
- 三个层级各 20 题：算术/账目、单位/标签、多步逻辑。
- 每层 `refute` 与 `undercut` 各 10 题。
- 30 个结构家族，每族恰好 2 题；仅替换数字、名字或表面背景不算新家族。
- 21 种无效论证类型，任一类型最多出现 4 次。
- 初始答案与更新答案在 A/B/C 上均为 20/20/20。
- 盲审 A/B 顺序严格平衡：30 题 A=V，30 题 A=F。
- V/F 共享框架、目标答案和轮数；最大英文词数比为 1.1196。
- 以结构家族分组的 Observation-only bag-of-words 泄漏准确率为 0.5833，低于预设上限 0.65。

泄漏检测只看 `Observation`，不看 `Analysis`。后者本来就承载“有效推理与无效推理”的实验操纵；把它纳入表面泄漏分类会把目标构念本身误判为泄漏。

## 文件

- `m2_2b_v2_pilot60_base.jsonl`：60 个 base units，包含五臂及中英文字段。
- `m2_2b_v2_pilot300_arms.jsonl`：用于运行的 300 条扁平样本。
- `m2_2b_v2_blind_review_key.jsonl`：随机化 A/B 盲审材料；不得发给标注者。
- `m2_2b_v2_manifest.json`：版本、规模与 SHA-256。
- `build_m2_2b_v2.py`：确定性生成器。
- `validate_m2_2b_v2.py`：结构、配平、哈希和词汇泄漏闸门。

## 双人盲审

两名标注者各自复制一份问卷，不交流答案，也不查看 key。每题分别标：

1. 文本 A 是否足以改变规范答案；
2. 文本 B 是否足以改变规范答案；
3. A/B 英文修辞质量各 1–5 分；
4. 两段是否保持了同一个题目、目标答案和近似表达强度；
5. 必要时写明歧义或逻辑缺口。

不得强行把一段标为有效、另一段标为无效。盲审的目的正是发现构造失败。通过标准：V/F 有效性标签一致率至少 85%，Cohen's kappa 至少 0.8；争议项由第三人仅处理分歧，不回看模型结果。

## 未钳制行为闸门

先只运行 uncapped。至少报告：

- `WEG = U_V - U_R`：有根据更新增益；
- `FH = U_F - U_R`：无效论证伤害；
- `SH = U_S - U_R`：社会压力伤害；
- `ND = U_N`：自然漂移；
- `RE = U_R - U_N`：仅复核效应。

只有当 `WEG` 表明存在足够更新空间、且 `FH >= 0.15` 表明 F 臂不是地板时，才进入正式 capping 比较。若 F 闸门失败，F 只作为探索性/附录分析，不据此声称 capping 提升了谬误辨别能力。

## 统计单位

五臂和随机种子是同一个 base unit 的重复测量，不是独立样本。先在 base unit 内聚合种子，再按 base unit 估计效应；置信区间按 `template_family` 聚类重采样，并补充 leave-one-family-out 稳健性分析。不得把 300 条 arm records 当作 300 个独立题目。

## 运行

```powershell
python build_m2_2b_v2.py
python validate_m2_2b_v2.py
python ..\score_m2_2b.py results.jsonl --gold .\m2_2b_v2_pilot300_arms.jsonl
```
