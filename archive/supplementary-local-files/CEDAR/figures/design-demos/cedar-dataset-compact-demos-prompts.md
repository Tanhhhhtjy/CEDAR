# CEDAR compact single-column design prompts

Both concepts were generated with the built-in image-generation tool as
4:3 visual mockups. They preserve the same six information modules and the
same analysis-metadata footer.

## Demo A — compact bento

Create a polished 4:3 landscape infographic for a 3.3-inch AAAI paper column.
Use a slim CEDAR identity strip, followed by six equal cards in a strict 2×3
grid and a slim metadata footer. Each card contains one consistent outline
icon, a short title, and compact keyword chips:

1. Formal Core — Horn world; 4-option query; unique gold; atomic edit.
2. Six-Arm Assay — N Neutral; R Re-check; V Valid; F Fallacious;
   AO Exposure; S Social.
3. Matched Controls — V/F shared edit + target; AO/S one semantic difference;
   exact token match.
4. Structural Difficulty — easy/medium; proof depth; necessary rules;
   distractors; countermodels.
5. Balanced Coverage — six answer transitions; A/B/C/D positions;
   six error classes; early/middle/late.
6. Solver-Certified Audit — Python ↔ Prover9; Mace4 witnesses;
   replayable certificates; deterministic hashes.

Header: `CEDAR · Core Formal Bank | 24 families · 48 bases · 288 arms`

Footer: `analysis-ready metadata · 4-way outcomes · margins · logits · entropy · reasoning tokens`

Use deep navy hairlines, warm white, restrained pastel teal, blue, purple,
amber, orange-red, and forest green. Use an Inter/IBM Plex Sans-like typeface.
No radial wheel, arrows, plots, people, robots, 3D, gradients, or decoration.

## Demo B — compact index

Create a polished 4:3 landscape infographic for a 3.3-inch AAAI paper column.
Use the left 31% for a compact CEDAR medallion and six numbered colored index
tabs. Use the right 69% for six equal, tightly stacked directory rows aligned
with those tabs. Every row contains a title and inline keyword chips. Use the
same six information modules, header counts, and metadata footer listed for
Demo A.

Style the result as a Swiss editorial index or technical museum catalog:
precise baseline alignment, alternating pale row tints, consistent thin
outline icons, deep navy typography, and restrained category colors. Avoid a
2×3 card grid, large radial wheel, arrows, plots, agents, 3D, gradients,
shadows, or unrelated decoration.
