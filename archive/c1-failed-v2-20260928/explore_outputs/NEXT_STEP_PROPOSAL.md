## 为什么改这一步

原“U/P 自然分量差的移植”可能很小，BF16 下部分随机对照无法在 0.5% 门槛内匹配。有限的正负等剂量干预直接检验：在同一候选方向上主动加减固定信号，是否改变答案读出。它改变了所回答的问题，不能伪装成原移植实验已完成，也不能用结果决定换随机向量或调门槛。

## 冻结的候选规则

- 模型、BF16、SDPA、p25、原始 token 序列和历史 cache-faithful runner 保持一致。主位点为 L53 cap 后、block 54 输入，最后一个 prompt token，prefill 时只修改一次。
- 每个 family 使用另外 11 个 family 的 U 条件 V/F 训练所得主 unit-RMS 方向；保留 nuisance、标准化逆映射和全部训练 ID。候选方向预测必须与原 P1 主分数一致。
- 信号剂量为 α=−1、+1 个训练投影标准差，映射回目标条件的原始隐藏状态；不重新归一化。U/P 使用同一 U-trained 方向和训练剂量定义，但须分别报告实际 BF16 位移。
- 固定随机向量沿用同一 family 的既定 seed。负剂量的随机向量必须反向：sign(α)·r；只沿这个已定向量二分标量，以匹配对应真实干预的实际 BF16 位移范数。相对误差门槛仍为 0.005，禁止更换随机向量、跳格子或改变精度。
- 原 S1 same-prompt 校准系数锁定；完整词表、no-op、重复性、局部替换和 hook 审计均保留。真实方向与随机方向的变化都应保存，不能只看真实方向。

## 52 次到底跑什么

首个字典序 base 的 N/R/V/F 四个 prompt × U/P 两种目标条件 × 六个操作：no-op、完整局部状态替换、真实 +1、真实 −1、random0 +1、random0 −1，共 48 次。再重复该 base 的 V prompt 在 U/P 两种条件下的 no-op 和真实 +1，共 4 次。合计 52 次。

它只验证程序和对照，不做 family 统计或机制宣称。一条 base 的结果不足以判断因果特异性，也不能选层、剂量、方向或丢弃无效条件。完整局部状态替换不等于全 KV cache 恢复。

门禁：全词表及保存数组 no-op/重复最大绝对差 <=1e-4；末端重建 <=0.25；真实模型 cached prompt 一致；每次修改一次；hook 调用数等于 prefix 长度+1；完整 hook 清理；所有数组有限；每个随机对照实际范数误差 <=0.5%。任意失败停止并保留全部记录。
