# CEDAR

**研究模型如何根据正确证据、错误论证和社会压力改变回答。**

## 目前已经得到的认识

早期实验发现，capping（限制模型内部某个方向的激活强度）对回答的影响依赖题目、提示和生成方式。我们最初期待的“干预越强，接受正确反驳的能力越差”没有稳定出现，部分设置反而增加了模型对错误论证或压力的跟随。

随后，我们固定模型看到的内容和后续文字，单独观察内部计算。capping 会改变不同答案的分数；整体分数尺度变化可以解释其中一部分，仍有剩余变化。模型内部也保留了可用于区分实验标签的信号。对某个候选方向进行局部干预后，预期的因果效果没有得到支持。最近的 B1/B2 实验进一步发现，评分变化主要在最终作答之前的历史计算阶段形成；当前实验尚未细分到具体缓存位置、注意力头或推理步骤。

这些结果逐步缩小了要解释的问题。固定重放中的分数变化与自然生成中的回答改变需要分别评估，后续研究将继续检验二者的联系。

## 目录与使用

`src/`、`scripts/`、`tests/`、`datasets/` 和 `artifacts/` 保留历史实验分支的代码与已跟踪产物。`archive/` 提供较新的冻结协议、分析代码和报告；对应大数据在 [Release](https://github.com/Tanhhhhtjy/CEDAR/releases/tag/archive-20261025)。`research/` 保存调研、路线复盘和历史论文版本。

各批代码具有各自冻结的环境和输入约定，复现时请从对应协议开始。历史监控脚本仅用于溯源，包含旧绝对路径与已取消的运行政策，不应直接启动。模型权重、环境目录、登录资料和私密对话未随本次归档发布。外部数据及代码沿用各自的授权条件；本次维护未新增覆盖第三方材料的许可证。
