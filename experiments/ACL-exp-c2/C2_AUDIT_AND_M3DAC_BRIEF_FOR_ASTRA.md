## 1. `ACL-exp-c2` 实验设计回顾（为什么这么设计）

### 1.1 问题重构（采纳上一轮三方复盘共识）
在 `ACL-exp-c1` Step 2B 触发 `STOP` 后，三方达成两项诊断共识：
1. **数据不变量误伤**：`c1_train_examples_wo_ce_nothink.jsonl` 中全部 800/800 核心 V/F 样例满足 `obs_entity == target_entity`，导致所有 8 组在合法跨实体交接 Row B 上塌缩至 `0.17%–0.85%`。`ACL-exp-c2` 改为**充分、无偏、全 5 类去捷径训练**，主战局转为“充分公平学习后，将 B1 机制写入训练算法的真实逻辑纠错上限”。
2. **定位与可塑性解离（Localization–Plasticity Dissociation）**：`ACL-exp-c1` 仅把 B1 定位当成静态 LoRA 参数掩码，仍用统一末端输出损失训练，把 B1 解剖出的三组电路分工丢弃了。

### 1.2 理论与算法：`Verification-Gated Three-Force Equilibrium` + `DAC-IIT`
我们辩证回归三力模型——**不盲目摧毁形式通路 $h_{\text{form}}$**（保留其对犹豫真证据 `V_hes` 与 `IFEval` 的正向推力），而是追求验证门控平衡态：
$$u^*(x) \approx h_{\text{init}}(x) + g\big(h_{\text{ver}}(x)\big) \cdot h_{\text{form}}(x) + h_{\text{ver}}(x)$$
对应 `c1_components_frozen.json` 中 `Qwen3-8B` `Targeted-Dual`（47 头 `r=14` + 5 层 MLP `[18,20,22,23,27]` `r=8`，总 `6,869,504` 参数）的**精确零交集 3 分区**（`23 + 21 + 3 = 47`）：
- **Form-Only Heads**（23 颗头）：`Targeted-Form \ Hub`
- **Ver-Only Pathway**（21 颗头 + 5 层 B1 MLP）：`Targeted-Dual \ Targeted-Form \ Hub` + 5 MLPs
- **Shared Routing Hub Heads**（3 颗头）：`[(19,31), (20,8), (21,19)]`

三级嵌套训练算法（`c2_train_iit.py`，全员统一 Standard 满血预算，`lr=3.5e-5`，300 步 = 1.0 epoch，`grad_accum=20` 即每步 2 组 10 项原子题，零人类回放，`accept_weight=2.0`，`lambda_margin=0.25, m=4.0`）：
- **Mode 0 (`base`)**：标准逐样本 `CE + Signed Readout Margin`。
- **Mode 1 (`paired2x2`)**：`base` + 精确两遍标量链式法则（CPU 自检与单批全图自动微分误差 `1.04e-7`，零额外显存）施加水平语气不变性（`SmoothL1(u(V_auth), u(V_hes)) + SmoothL1(u(F_auth), u(F_hes)) + SmoothL1(ReLU(u(shell_only) - sg(u(AO)) - 1.0), 0)`，$\lambda_{\text{inv}}=0.15$）与垂直证据敏锐度边距（`mean_{t∈{plain,auth,hes}} ReLU(6.0 - (u(V_t)-u(F_t)))`，$\lambda_{\text{sens}}=0.25$）。
- **Mode 2 (`dac_iit`)**：`paired2x2` + 双通路可微激活互换干预训练（作用于 `answer_readout_pos` 结尾 `k ≤ 8` 个完全对齐的助手读出后缀 token，推理零开销）：
  1. 跨语气互换 `Form-Only` 23 颗头的 `o_proj` 输入切片（`V_hes ↔ V_auth`, `F_hes ↔ F_auth`），要求输出不变且符号正确（$\lambda_{\text{iit\_form}}=0.15$）；
  2. 同语气异真伪互换 `Ver-Only` 21 颗头 `o_proj` 切片 + 5 层 `Ver-MLP` 输出（`F_t ← V_t` 与 `V_t ← F_t`，覆盖 `plain/auth/hes`），要求输出反事实翻转过 `margin_iit=3.0`（$\lambda_{\text{iit\_ver}}=0.25$）；
  3. 刻意不覆盖 3 颗 `Hub Heads`，迫使其学习条件门控。

### 1.3 8 卡 2×2 因子交互矩阵（`Location × Algorithm`）
- `Targeted-Dual`（B1 真实 3 分区）：`dac_base`、`dac_paired`、`dac_iit`
- `Random-LM` / `Random-LM-seed2`（**逐层精确等头数随机 3 分区** `(23/21/3)` + 5 层随机 MLP）：`rnd1_base`、`rnd1_iit`、`rnd2_iit`
- `Uniform-LoRA`（全 36 层 `q/o/gate/down` @ `r=4`，`7,077,888` 参数）：`unif_base`、`unif_paired`

### 1.4 数据与三轴评测（零泄漏 + 零捷径实测认证）
- **训练集 `c2_train_examples_nothink.jsonl`（600 题 × 10 项原子组 = 6,000 条）**：启用 **6 个全新 C2 独占域**（与 A1、C1 含封存测试集、Proxy 域数学无交集）；5 类 × 120 题（其中 `cross_entity_transfer` 为 **60 组完整 2×2 Row A/B 对称单元**），Style A/B 各 300 题（与 `c1_proxy_template_v2` 骨架重合 `0/120`），G0 TF-IDF GroupKFold AUC = `0.4873` (`CF=1.0`)。每组 10 项完整含 `V, F, V_auth, V_hes, F_auth, F_hes, shell_only, AO, S` + 轮换 `{P0, I0, F_src_3p, N}`。
- **轴 1 `c2_confirm_bidir`（360 题，Proxy 6 域）**：5 类 × 72 题（含 36 组完整 2×2 CE 单元），G0 AUC `0.4288` (`CF=1.0`)。主指标：**修辞倒置双向双对 `DC(V_hes, F_auth)`**。M0 合格基数：`no_think = 239/360`，`think = 360/360`。
- **轴 2 `c2_stealth_stress`（180 题，严禁 `converse_error` 与 `depth-4`）**：
  - `stealth_late_buried`（120 题）：Depth-3 + 4 诱饵，前两跳求解器验证 100% 合法，**仅 Step 3 隐藏单原子断裂**，`context_flip` 逐字节双胞胎（G0 AUC = `0.5000`, `CF=1.0`）；M0 合格基数 `no_think = 43/120`、`think = 120/120`。
  - `classical_natural_sophisms`（60 题，**100% 零样本自然语言迁移**）：4 类亚里士多德/古希腊经典隐蔽诡辩（*Petitio Principii 循环论证*、*Equivocation 偷换概念*、*False Cause 虚假因果*、*Suppressed Condition 隐瞒例外条件*）各 15 题，统一 `"Case update:"` 前缀，V/F 长度比均值 `0.955`；M0 合格基数 `no_think = 54/60`、`think = 58/60`。
- **轴 3 护盾**：`c1_proxy_template_v2 (120)`、`c1_dev (80)`、`S / shell_only / P0 / I0`、`IFEval (541)`、`GSM8K (1,319)`、`WikiText-2 KL (200)`、逐组 SHA 绑定 vLLM 0.11.0 原生 LoRA 保真校验与 BF16 权重舍入审计。

### 1.5 运行期两起工程插曲与无损处理（均已完整记档）
1. **梯度检查点重算 `src` 长度不匹配（`b838ef18`）**：首跑 IIT 时，`src` 与 `tgt` 长度不同，`use_reentrant=False` 反向重算 `src` 层时误触发了 `tgt` 的 `patch_hooks`；服务器已于 step 0 干净修复为隔离 target hook（`gc_diff = 0.00e+00`）并从 `seed=42, step=0` 全量重训 3 组 IIT。
2. **保真 `du_abs_mean` 阈值过严拦截 `dac_iit` 与 `unif_paired`（`1fa8d61`）**：`dac_iit`（`option_match = 79/80 = 98.75%`, `u_coverage = 1.0`, `du_signed = +0.0058`, `du_abs = 0.381`）与 `unif_paired`（`option_match = 80/80 = 100.0%`, `0` 翻转, `du_signed = -0.0187`, `du_abs = 0.372`）因旧上限 `0.35` 仅超出 `0.02–0.03` 被暂停；校准至 `--max-abs-du-mean 0.50` 后直接复用磁盘原权重零重训完成全量补评（SHA-256 严格一致：`dac_iit 7fb112d0...`、`unif_paired 3f2a78da...`）。

## 4. 拟议下一阶段方法论：`M3-DAC`（三区因地制宜机理适配架构，候选 `ACL-exp-c3`）

基于项目负责人“全链路优化、各区因地制宜、精细区分中层头、顶层解耦形式并平衡放缩与自信、绝不盲目顽固”的核心思想，我们提炼出一套 **4 模块、零推理开销、严格可消融** 的统一框架：

### 模块 1 · 底层（Zone 1: `L0–13` / 14B `L0–15`）：**两阶段残差解冻 + 近端锚定**
- **Phase 1（前 30% 步数，如 Steps 1–80）**：冻结 Zone 1，仅训 Zone 2 + Zone 3，优先用中顶层解锁所有 M0 已有能力（将简单题损失压至 `≈ 0`）。
- **Phase 2（后 70% 步数，Steps 81–250/300）**：解冻 Zone 1 超低秩轻桥（`r=2`、`lr_Z1 = 0.35 × lr`）+ 近端正则 $\lambda_{\text{prox}}\|\Delta W_{Z1}\|_F^2$。由链式法则自然保证：**已由中顶层解决的题对底层零梯度，仅残差未解的多跳/跨实体难题驱动底层建立最小必要连接**，避免通用语言漂移与网络固化。

### 模块 2 · 中层（Zone 2: `L14–27` / 14B `L16–30`）：**4 角色细化 + 因果质量自适应秩分配 + 温和走廊 IIT**
- **因果质量自适应秩（Causal-Mass-Proportional Rank Allocation）**：在严格保持总参数量与基线对齐的前提下，按 B1 因果质量 $w_{\ell,h}$ 为每颗头分配分级秩（核心枢纽与 Top-10 头 `r=20–24`，中游头 `r=10–12`，长尾头 `r=4–6`），替代一刀切 `r=14`。
- **4 角色差异化介入**：将天生抗形式卫士（如 `L19H13 / L17H15`）划入核验保护侧而非形式压制侧；仅对纯形式/反逻辑头做跨语气条件去偏互换；对纯核验头 + 中层 5 MLP 做反事实翻转互换，**且仅当样本未进入置信走廊（$|u| < m_{\min}$）或按余弦衰减激活**，杜绝过饱和。

### 模块 3 · 顶层（Zone 3: `L28–35` / 14B `L31–39`）：**补齐推拉刹车头与对话 MLP + “双边置信走廊”控放缩**
- **补齐 B1 实证顶层组件**：纳入顶层推拉对偶 `DLA` 头（8B `L35H25/24/27, L34H29/30/28, L29H05/06`）与顶层对话态核验 MLP（8B `[29, 32, 35]`，14B `[33, 38, 39]`），让中层分好的逻辑信号在顶层真正摆脱形式劫持。
- **双边置信走廊（Confidence Corridor）+ 零偏移对称权重 + 轻度 RMS 锚定**：
  $$\ell_{\text{corridor}}(u, y) = \operatorname{ReLU}(m_{\min} - y \cdot u) + \lambda_{\text{cap}} \operatorname{ReLU}(|u| - m_{\max})^2, \quad [m_{\min}, m_{\max}] = [4.5, 10.0]$$
  - 既把判断推过 `+4.5 / -4.5` 摆脱犹豫与随机噪声，又用 `m_max = 10.0` 硬刹住 `±35` 过自信顽固漂移；
  - 废除造成 `+4` 分阈值偏移的 `--accept-weight 2.0`，改为核心 `V/F` 1:1 严格对称、辅助拒答臂（`AO/S/shell`）轻权 `0.4`，使最优切分点自然回中 `u = 0.0`；
  - 可选加极轻量末层 `RMS(h_L)` 锚定，直接呼应 B1 残差读出方程 $u \propto \Delta w_U^\top h_L / \operatorname{RMS}(h_L)$，阻止顶层靠全局范数放缩投机。

### 模块 4 · 训练数据去 Step-1 偏置
- 保持 6 个 C2 独占训练域与零 `converse_error` / 零 `depth-4` 铁律，仅将 3 跳训练题的逻辑断点在 **Step 1 / Step 2 / Step 3 均衡轮换**（同时保留一个**完全未见的高隐蔽新组合压力切片**用于评测，避免测试集同分布泄题！）。

### 拟议 8 卡干净消融矩阵（`Qwen3-8B`，严格总参数量对齐 ~`7.0M`，待 Astra 评审敲定！）
1. **`unif_base`**（强基线参照，直接复用 C2 或重跑同新数据）
2. **`unif_corridor`**（检验“双边置信走廊 + 零偏移权重”本身对全网 LoRA 的净增益，排除新损失函数单独赢）
3. **`unif_b1_iit`**（**关键解耦检验**：全网 `Uniform-LoRA` 可塑性 + B1 温和走廊 IIT，验证解除底层冻结后 B1-IIT 能否把上限推过 `unif_base` / `unif_corridor`！）
4. **`unif_rnd_iit`**（同预算全网 `Uniform-LoRA` + 逐层随机分区 IIT，与 #3 构成全网下的纯净定位对照！）
5. **`m3_z23_corridor`**（仅 Zone 2 因果自适应秩 + Zone 3 刹车头/对话 MLP + 走廊，**不动 Zone 1** — 检验补齐顶层与自适应秩后能否追平甚至超全网！）
6. **`m3_full_no_iit`**（Zone 1 两阶段残差解冻 + Zone 2 因果自适应秩 + Zone 3 刹车头/对话 MLP + 走廊，**不含 IIT**）
7. **`m3_full_iit`**（**完全体 `M3-DAC`**：Zone 1+2+3 + 因果质量自适应 + 走廊 + 温和 B1-IIT）
8. **`m3_random_control`**（严格同三区预算、同两阶段解冻、同走廊、同 IIT，但 Zone 2/3 头与 MLP 逐层随机替换，彻底检验结构定位净贡献！）
