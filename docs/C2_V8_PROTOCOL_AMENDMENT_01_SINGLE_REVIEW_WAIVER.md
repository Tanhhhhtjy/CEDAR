# C2/V8 协议修正案 01：单一数据负责人审核豁免

状态：GPU 前冻结修正案  
日期：2026-07-22  
适用实验：C2/V8 外部自然社会压力确认实验

## 修正内容

原冻结协议要求从 600 个 base 中分层抽取 120 对 AO/S，由两名独立审核者分别判断
AO 纯度、S 纯度、S 是否增加新信息、语言自然度和 target 映射，并报告原始一致率与
Cohen's kappa。

数据负责人已经人工检查完整的 600-base 数据、1,200 条 AO/S 展开记录及冻结的 120 对
审核材料，确认题目、AO/S 映射、构念纯度、target 映射和语言自然度均通过。因时间限制，
本轮取消第二名独立审核者，改为：

```text
单一数据负责人全量审核 + 自动化全量构建验证
```

本修正案是明确的协议偏离，不是双人审核的替代性证明。本轮：

- 不创建或代填虚假的 `review_a_completed.csv`、`review_b_completed.csv`；
- 不报告双人原始一致率；
- 不报告 Cohen's kappa；
- Gate 中上述两项必须为 `null`；
- 后续论文和交付只能写成“单一数据负责人审核＋自动化全量验证”；
- 人工质量控制证据弱于原预注册的双人独立审核。

单人审核声明必须绑定冻结审核包的规范化内容哈希、120 个 review ID 的集合哈希、当前
600 base 和 1,200 arms 的对象哈希，以及本修正案的 LF 规范化文本哈希。验证器同时保留
原双人审核路径；本次执行只使用明确披露的单人 waiver 路径。

## 时间与输出盲性

本修正案和单人审核声明在查看或生成任何 C2/V8 Qwen、uncapped、p25、smoke、direct
或 free-generation 输出之前冻结。修正时：

- 未运行 Qwen；
- 未使用 GPU；
- 未安装或运行 p25；
- 未产生 C2/V8 模型输出；
- 未依据模型行为修改数据、模板、target 或样本。

GPU 只能从包含本修正案、审核声明、通过的 `HUMAN_REVIEW_GATE.json` 和跨平台规范化哈希
preflight 的干净提交开始。Runner 在启动时记录实际 `git rev-parse HEAD`，不把当前提交
SHA 写回受该提交约束的文件，避免循环依赖。

## 跨平台哈希修正

所有受执行硬闸约束的 UTF-8 文本使用 `utf8_lf_canonical_v1`：先将 CRLF 和 CR 统一为
LF，再计算 SHA-256。JSON/JSONL 的科学内容身份使用解析后的有序对象哈希。原始字节
SHA-256 和字节数仅作诊断，不作为 Windows/Linux 间的通过条件；Git blob ID 与 LF
规范化 SHA-256 共同记录。

该修正只改变审核授权和工程身份检查，不改变数据对象、prompt、模型、生成配置、p25、
层范围、主要终点、bootstrap 或解释规则。
