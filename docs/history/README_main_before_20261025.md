# CEDAR

**C**ost of **E**pistemology under **D**rift-suppressing **A**ctivation **R**estraint

> 激活钳制的认识论代价 · The Epistemic Cost of Activation Capping

本项目研究一个被现有安全干预评测忽略的科学问题：用于稳定大语言模型人格、抑制人格漂移（persona drift）的 **激活钳制（activation capping）**，在压制"被社会压力带跑的漂移"的同时，是否一并误伤了"应当由证据触发的**合理信念更新**（warranted belief revision）"。我们将这一被误伤的合理更新量命名为 **认识论代价（epistemic cost）**。

## 研究动机

近期工作 **Assistant Axis**（Lu et al., arXiv:2601.10387）提出激活钳制：当模型激活在"助手轴"上的投影超过阈值时，将其强制拉回阈值内：

```
h ← h − v · min(⟨h, v⟩ − τ, 0)
```

其报告可将有害顺从降低约 60%，且在四项静态能力基准（IFEval、MMLU-Pro、GSM8k、EQ-Bench）上"不损伤能力"。**但这四项基准均为静态任务**，无一考察一种动态能力——当模型持有某立场、外界提供有效新证据时，它能否合理地修正立场。

核心假设：**激活钳制在抑制坏漂移的同时，很可能一并压制了本应由证据触发的合理信念更新。** 其几何根源在于两类立场变化在激活空间中运动方向高度重叠，而钳制沿单一固定方向施力，无法区分二者。

## 三段式研究结构

| 层次 | 科学问题 | 产出 | 风险独立性 |
|------|----------|------|-----------|
| **测量** | 认识论代价是否存在、有多大？ | 「减害量—合理更新保留率」权衡曲线 | 保底贡献，纯行为评测 |
| **解释** | 该代价为何存在？ | 逐样本"投影—压制"机制回归 | 依赖读取协议；失败降级为讨论 |
| **降低** | 该代价能否规避？ | 门控正交钳制及其权衡曲线 | 探索性；失败记为负结果 |

这一"测量 → 解释 → 降低"弧线使项目具备稳固下限，同时保留冲击更高目标的空间。

## 三段贡献

- **贡献一 · 测量（主贡献）**：扫描钳制强度，绘制"能力—认识论双 Pareto 前沿"，寻找解离点（能力基准无损但合理更新显著受损的钳制强度）。
- **贡献二 · 解释（机制）**：验证"一次合理更新在被钳制轴上的投影越大，其被压制越深"，以散点回归 + 偏相关 + 置换零模型呈现。
- **贡献三 · 降低（方法创新）**：**门控正交钳制（L2）**——将"正交"从发力方向推进到钳制专属的触发条件，这一动作在无条件 steering 框架中原理上无法实现。

| 级别 | 触发条件 | 发力方向 | 谁曾实现 |
|------|----------|----------|----------|
| L0 朴素钳制 | 全轴投影 ⟨h,v⟩ | 沿全轴 v | Assistant Axis |
| L1 方向正交 | 全轴投影 | 沿正交方向 (I−P_U)v | 业界成熟 |
| L2 门控正交 | 仅正交分量 ⟨h,(I−P_U)v⟩ | 沿正交方向 | 无人实现，钳制专属 |

## 方法论加固

- **双地板校准 + 等价性检验（TOST）**：防止高维近正交使"可分"成为廉价必然。
- **标准化读出协议**：固定探测模板 + 固定位置读激活，剥离内容方差。
- **价值域形式化判据**：以事实前提的逻辑否定客观定义"该更新"，避免裁判自指循环。
- **局部切空间保护区**：按话题聚类、逐邻域估计局部线性 U_k（信念是低维弯曲流形）。
- **27B / 9B 双模型**：主曲线在 Gemma-2-27B（原文验证规模），机制分析在 9B（SAE 工具最全）。

## 主力模型与工具链

- **模型**：Gemma-2-27B（主曲线）+ Gemma-2-9B / Llama-3.1-8B（机制分析）。硬件 8×4090（约 192GB 显存，张量并行）。
- **工具**：TransformerLens、nnsight / pyvene、repeng / steering-vectors、SAELens + Gemma Scope、circuit-tracer。
