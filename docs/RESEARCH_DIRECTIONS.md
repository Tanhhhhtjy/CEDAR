# 研究方向与文献调研

目前的总问题是：模型怎样结合正确证据、错误论证和社会压力作出决定，这种能力又怎样在训练和推理中形成。我们保留多种候选方向，用小规模、能区分解释的预实验逐步选择。

建议按以下顺序阅读：

1. [研究重审：2026-10-20](../research/notes/CEDAR_RESEARCH_RESET_20261020.md)：取消旧 ARR 排期，重新审查测量与路线选择。
2. [起点及转向 capping 的复盘](../research/notes/CEDAR_ORIGIN_AND_CAPPING_TURN_RETROSPECTIVE_20261020.md)：最初关切、文献讨论与关键决策。
3. [经文献调研修订的方向草稿](../research/notes/CEDAR_FUTURE_DIRECTIONS_LITERATURE_REVISED_20261025.md)：继续 capping、定向微调、KV 缓存/压缩、注意力架构、预训练、后训练、上下文等候选。
4. [文献对照与进一步研究空间](../research/notes/CEDAR_FUTURE_DIRECTIONS_LITERATURE_MAP_20261025.md)：已有工作做到了什么，以及我们可以如何在其基础上推进。
5. [引用检查记录](../research/notes/CEDAR_FUTURE_DIRECTIONS_CITATION_CHECK_20261025.md)：本轮核验范围和修正。

[微调专题调研](../research/notes/CEDAR_FINETUNING_RESEARCH_ASSESSMENT_20261021.md)与训练路径资料也完整保留。其中早期优先级建议属于讨论记录；用户随后明确选择保留多条路线，当前没有确定微调为主线。

`research/history/` 保存早期思想文档、模拟评审意见、研究工具和多轮论文草稿。模拟评审属于规划反馈，其意见不构成独立实验结果。`research/manuscripts/` 保存历史稿件，当前发现和项目状态以首页及最新完成报告为入口。

H、JEV 和后续定位设计位于 [B 批归档](../archive/b1b2-20261006/) 及 [C1 的 H1 设计](../archive/c1-signed-20261003/h1_design/)。这些文件可作为重新评估的材料；本次归档没有启动对应模型实验。
