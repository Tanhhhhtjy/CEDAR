# Experiment Plan

1. Freeze source audit and comparison protocol.
2. Define one signed finite-Horn schema, eight families, and sixteen common specifications.
3. Implement independent Prover9 and Python evaluators plus route-neutral validation.
4. Run two unscored sentinels through both construction styles and freeze hashes.
5. Run exactly sixteen attempts per route with a budget of 100 candidate worlds each.
6. Preserve valid and failed outputs, traces, proofs, countermodels, attempts, and timing buckets.
7. Rebuild twice and compare canonical hashes.
8. Render eight deterministic English naturalization sentinels.
9. Compute hard gates, difficulty control, route score, failure catalog, and final decision.
10. Push the comparison and stop before any development-bank, S, Qwen, GPU, or capping work.

The independent variable is construction style. Logic specifications, solver, evaluator, search
budget, schema, validity rules, and scoring are fixed controls.
