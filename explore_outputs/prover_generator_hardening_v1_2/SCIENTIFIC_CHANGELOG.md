# Scientific Changelog

## v1.2 construct revision

Phase 1.1 remains closed at Gate C. Version 1.2 changes the naturalization construct from
`official update versus fallacious suggestion` to `same-source paired justification`. It adds the
meta-query `revision_warranted(edit_id)` and applies the already frozen atomic edit only when that
query is proved.

The twelve sentinels reuse v1.1 rows only as immutable base-question and edit anchors. Their
justification worlds, V proofs, F countermodels, paired language, and review packet are new. This
is a protocol revision, not a renderer-only amendment and not a claim that the development-bank
generator is complete.
